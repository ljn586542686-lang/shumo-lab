# U3 竞争点强制生成规则

状态：`PASS_WITH_LIMITATION / U3_COMPETITIVE_RED_TEAM_AND_HIGH_AWARD_GATE_READY`

## 1. 基本要求

每篇正式候选论文至少必须生成 1-2 个可辩护竞争点。没有竞争点时，不得标记为高奖候选。

命中状态：

`PASS_WITH_LIMITATION / NO_DEFENSIBLE_COMPETITIVE_HIGHLIGHT`

## 2. 竞争点来源

竞争点可以来自：

1. 机理启发特征；
2. 正式优化建模；
3. 边界风险控制；
4. 鲁棒候选排序；
5. 序贯实验设计；
6. 不确定性量化；
7. 稳定性 / 时间序列增强；
8. 图网络 / 调度 / 覆盖问题中的结构性创新；
9. 评价类题中的指标体系鲁棒性；
10. 统计类题中的验证和解释增强。

## 3. 不合格竞争点

以下内容不能算竞争点：

- 章节结构完整；
- 图表数量多；
- 使用多个模型但没有角色分工；
- 使用 GA/PSO/SA 但没有可行域和约束解释；
- 把黑箱模型指标写得更好；
- 把候选点写成最优；
- 堆术语但没有实质证据。

## 4. 输出要求

竞争点必须写清：

- 来自哪个问题；
- 支撑它的数据或模型；
- 相比 baseline 的改进；
- 风险和限制；
- 可被评委追问时如何防守。
