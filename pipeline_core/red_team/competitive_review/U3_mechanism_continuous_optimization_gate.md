# U3 机理启发与连续优化闸门

状态：`PASS_WITH_LIMITATION / U3_COMPETITIVE_RED_TEAM_AND_HIGH_AWARD_GATE_READY`

## 1. 适用范围

适用于化学题、物理题、工程过程题、机制题，以及任何试图从离散数据扩展到连续优化的问题。

## 2. 机理启发特征工程闸门

必须先判断是否存在可拆解变量：

1. 催化剂成分；
2. 金属负载量；
3. 载体类型；
4. 装料比例；
5. 浓度；
6. 温度；
7. 时间；
8. 流速；
9. 结构参数；
10. 工艺条件。

若存在可拆解变量，优先生成：

- 机理启发特征工程；
- 半经验模型；
- surrogate model；
- 受约束优化；
- 不确定性量化。

若不存在可拆解变量，禁止硬写机理模型，禁止虚构活化能、速率常数、动力学 ODE、连续配方最优。只能保留：

- 离散枚举；
- 候选排序；
- 稳健性分析；
- 后续实验设计。

## 3. Arrhenius / 速率方程限制

只有在存在足够速率、浓度、时间、温度数据时才允许建立 Arrhenius、反应速率方程或活化能估计。否则只能写“机理启发半经验模型”。

## 4. 连续配方优化可行性闸门

连续配方优化必须同时满足：

1. 数据中能把每个编号还原为具体配方变量；
2. 配方变量具有连续或半连续意义；
3. 能定义合理约束域；
4. 能避免优化算法跑到物理不可行或实验未覆盖区域；
5. 有不确定性量化说明候选点可信度。

不可行时：

- 不得凭空做连续配方优化；
- 不得宣称突破真实收率上限；
- 不得把数据外候选写成已验证最优；
- 只能提出理论候选或后续实验候选。

## 5. 优化算法限制

不得为了显得高级而盲目接 GA、PSO、SA。只有变量连续化、约束明确、代理模型可靠、搜索空间足够大时，才允许调用 GA / PSO / SA / 贝叶斯优化 / Kriging / GPR。
