# U3 红队攻击分类表

状态：`PASS_WITH_LIMITATION / U3_COMPETITIVE_RED_TEAM_AND_HIGH_AWARD_GATE_READY`

## 1. 攻击面总览

| 攻击类别 | 典型攻击话术 | 风险等级 | 应对方向 |
|---|---|---|---|
| 模板痕迹 | 论文像系统拼接，缺少问题驱动叙述 | S2 | 表达润色、问题驱动重写 |
| 优化不足 | 只是拟合后取最大值，没有目标函数和约束 | S1 | 优化正式化、候选排序 |
| 边界最优 | 推荐点在最高温度或最大剂量边界，可信度弱 | S1 | 边界风险、邻域敏感性、不确定性 |
| 机理薄弱 | 化学/物理题只用 dummy 编号和黑盒拟合 | S1 | 机理启发变量、半经验模型 |
| 不确定性不足 | 单点预测支撑结论，没有置信范围 | S1 | Bootstrap、扰动、预测区间 |
| 稳定性单薄 | 时间数据只描述，没有衰减率或趋势模型 | S1 | 时间序列 / 稳定性触发器 |
| AI 半成品味 | 正文像报告或提示词产物 | S2 | 学术表达、人工复核痕迹 |
| 合规残留 | 候选稿、占位、状态码进正文 | S0 | 正式提交阻断 |
| 引用伪装 | placeholder 被写成正式 references | S0 | reference guard |
| 结果越界 | 预测写成实验真实结果、baseline 写成全局最优 | S0 | 结论边界和证据链 |

## 2. 强队常见攻击点

1. 你只是把数据拟合了一遍，没有真正建优化模型。
2. 你的最优在边界，可能只是数据范围不够。
3. 你没有说明为什么这个模型比简单方法更可信。
4. 你没有给不确定性，排序可能不稳。
5. 你没有把机理变量拆出来，dummy 编号没有解释力。
6. 你把附件的时间数据当附属描述，没有形成稳定性模型。
7. 你图表很多，但没有一个真正支撑核心结论。
8. 你参考文献像占位，不像真实核验过的引用。
9. 你的 AI 使用说明像模板，不像真实披露。
10. 你的论文格式像候选稿，不像正式投稿。
