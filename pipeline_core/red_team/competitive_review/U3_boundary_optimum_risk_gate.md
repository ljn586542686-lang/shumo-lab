# U3 边界最优风险闸门

状态：`PASS_WITH_LIMITATION / U3_COMPETITIVE_RED_TEAM_AND_HIGH_AWARD_GATE_READY`

## 1. 触发条件

凡模型推荐点位于变量边界，必须触发本闸门。例如：

- 最高温度；
- 最低温度；
- 最大浓度；
- 最大剂量；
- 最大预算；
- 最短时间；
- 最大会员密度；
- 任何变量可行域端点。

## 2. 禁止表述

边界候选不得写成：

- 全局最优；
- 真实最优；
- 已验证最优；
- 最终最优方案；
- 可直接实施的最优点。

## 3. 推荐表述

应改写为：

- 当前实验范围内优先候选；
- 模型预测下的边界候选点；
- 建议优先复核方向；
- 数据范围内候选方案；
- 需要边界加密实验验证的方案。

## 4. 强制补充项

边界候选必须至少补充以下若干项：

- 邻域敏感性分析；
- 预测区间或置信区间；
- Bootstrap 或蒙特卡洛扰动；
- 候选方案鲁棒排序；
- 边界附近加密实验；
- 序贯实验方案。

若未补充，状态为：

`PASS_WITH_LIMITATION / BOUNDARY_OPTIMUM_RISK_UNRESOLVED`

## 5. 2021B 适用说明

2021B 中 A1、450 ℃属于最高温度边界候选，必须写成“当前模型和观测范围下的优先验证候选”，不得写成全局最优。
