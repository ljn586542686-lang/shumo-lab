# U3 不确定性量化触发器

状态：`PASS_WITH_LIMITATION / U3_COMPETITIVE_RED_TEAM_AND_HIGH_AWARD_GATE_READY`

## 1. 触发条件

当论文出现以下任一情况，必须触发不确定性量化：

1. 推荐最优方案；
2. 推荐候选排序；
3. 最优点位于边界；
4. 存在外推；
5. 使用预测值支撑实验设计；
6. 使用模型结果做排序；
7. 样本量较小；
8. 模型间结论不一致；
9. 高收率或高收益候选；
10. 结论用于实际决策。

## 2. 至少需要生成的内容

必须至少生成以下之一：

- 预测区间；
- 置信区间；
- Bootstrap；
- 蒙特卡洛扰动；
- 参数敏感性；
- 残差风险说明；
- 候选方案鲁棒排序；
- 风险等级表。

## 3. 未满足时状态

若触发条件存在但未做不确定性量化，状态为：

`PASS_WITH_LIMITATION / UNCERTAINTY_QUANTIFICATION_REQUIRED`

## 4. 证据链要求

不确定性数值必须来自实际计算或明确的人工复核，不得凭空生成。若尚未运行，只能写为“需要补充”，不能写成定量结果。
