# 验证指标目录

状态：`PASS_WITH_LIMITATION / PROBLEM_ROUTING_MODEL_LIBRARY_BASELINE_READY`

## 1. 回归类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| MAE | 平均绝对误差，易解释 | 对大误差不敏感 |
| RMSE | 强调大误差 | 易受异常值影响 |
| R² | 拟合解释度 | 高 R² 不等于可外推 |
| 残差分析 | 检查系统偏差 | 需要图表和统计口径 |

## 2. 分类类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| accuracy | 总体正确率 | 类别不平衡时误导 |
| precision | 正类预测准确性 | 需明确正类 |
| recall | 正类召回能力 | 需结合 precision |
| F1 | precision 和 recall 折中 | 不反映概率校准 |
| AUC | 阈值无关排序能力 | 不等于实际收益 |

## 3. 预测类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| MAPE | 相对误差 | 真实值接近 0 时失真 |
| RMSE | 预测误差 | 受异常点影响 |
| 滚动验证 | 模拟真实外推 | 样本少时波动大 |
| 残差自相关 | 检查未建模结构 | 需要时间顺序明确 |

## 4. 优化类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| 目标函数值 | 衡量方案优劣 | 需与约束同时报告 |
| 约束满足率 | 检查可行性 | 不等于最优性 |
| 可行性 | 判断方案是否满足硬约束 | 缺约束时无意义 |
| 敏感性 | 检查参数扰动影响 | 不能替代全局最优证明 |

## 5. 评价类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| 排序稳定性 | 检查 TopN 是否稳健 | 权重变化大时需披露 |
| 权重敏感性 | 检查主观权重影响 | 不能消除主观性 |
| 一致性 | AHP 等判断矩阵检查 | 只检查矩阵，不证明指标正确 |

## 6. 图网络类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| 覆盖率 | 服务范围评价 | 阈值依赖强 |
| 平均响应时间 | 服务效率 | 受边权近似影响 |
| 最大响应时间 | 极端节点风险 | 易被孤立点影响 |
| 连通性 | 网络可达性 | 不说明服务质量 |

## 7. 调度类指标

| 指标 | 用途 | 风险 |
|---|---|---|
| 吞吐量 | 产出能力 | 需明确班次边界 |
| 等待时间 | 资源空闲或拥堵 | 需区分 RGV/CNC/客户等待 |
| 利用率 | 设备负载 | 高利用率不一定好 |
| 仿真重复稳定性 | 随机仿真稳健性 | 确定性仿真也需口径审计 |
