# 敏感性分析目录

状态：`PASS_WITH_LIMITATION / PROBLEM_ROUTING_MODEL_LIBRARY_BASELINE_READY`

敏感性分析只用于检查结果稳健性，不能替代模型证明，也不能把未运行出的扰动结果写成定量结论。

## 1. 参数扰动

适用：机理拟合、优化、调度、预测。

常见做法：核心参数上下浮动 5% 或 10%，比较关键输出。

风险：扰动范围必须有依据，不能随意解释为真实不确定性。

## 2. 权重扰动

适用：评价决策、多目标优化、综合评分。

常见做法：提高或降低某类指标权重，检查排序或方案变化。

风险：权重扰动不能消除权重主观性。

## 3. 阈值扰动

适用：分类、覆盖、筛选、任务完成概率。

常见做法：调整分类阈值、覆盖半径、距离半径或完成概率阈值。

风险：阈值变化可能改变结论，必须披露。

## 4. 约束边界扰动

适用：优化规划、调度、资源分配。

常见做法：调整预算、容量、时间窗口、供应上限。

风险：约束扰动只说明局部稳定性，不证明全局最优。

## 5. 异常值处理敏感性

适用：统计分析、预测、分类、空间分析。

常见做法：保留异常值、排除异常值、人工确认后修正三种口径比较。

风险：不得静默删除或改值。

## 6. 数据缺失处理敏感性

适用：所有数据驱动模型。

常见做法：不填补、均值/中位数填补、模型填补或只用完整样本对比。

风险：填补方法必须披露，关键字段缺失可能阻断建模。

## 7. 方案对比敏感性

适用：优化、调度、定价、选址。

常见做法：baseline、保守方案、均衡方案、激进方案对比。

风险：方案对比不等于最优性证明。

## 8. 预测模型特征敏感性

适用：预测、分类、完成概率模型。

常见做法：删除某类特征、加入派生特征、改变训练验证划分。

风险：特征贡献不能直接解释为因果关系。
