# 模型路线注册表

状态：`PASS_WITH_LIMITATION / PROBLEM_ROUTING_MODEL_LIBRARY_BASELINE_READY`

本文件是 `model_route_registry.json` 的人类可读版本，用于人工选择路线、检查模型边界和准备论文结构。它不代表自动锁定模型，也不授权进入 `final_submit/`。

## 1. baseline 与 advanced 的区别

| 类型 | 定义 | 可写内容 | 不可写内容 |
|---|---|---|---|
| baseline | 低复杂度、可解释、用于验证数据链路和形成最小闭环的模型 | “基准模型”“初步方案”“用于压测或阶段性分析” | “全局最优”“最终正式方案”“完整解决赛题” |
| advanced | 在 baseline 验证后可扩展的更复杂模型 | “候选增强路线”“需额外验证”“可能改善结果” | “未运行即证明优于 baseline” |

## 2. 各题型推荐路线

| 题型 | baseline 路线 | advanced 路线 | 主要验证指标 |
|---|---|---|---|
| 统计分析类 | 描述统计、分组对比、相关性分析、logistic baseline | 广义线性模型、树模型解释、因果候选模型 | 缺失率、相关系数、accuracy、AUC、残差 |
| 预测时间序列类 | 移动平均、指数平滑、ARIMA baseline | SARIMA、状态空间、机器学习预测 baseline | MAPE、RMSE、滚动验证、残差自相关 |
| 优化规划类 | 线性规划、规则启发式、贪心 baseline | 整数规划、非线性规划、多目标优化、遗传算法 | 目标函数值、约束满足率、可行性、敏感性 |
| 评价决策类 | 标准化综合评分、熵权法、TOPSIS baseline | AHP-TOPSIS、PCA、灰色关联分析 | 排序稳定性、权重敏感性、一致性 |
| 图网络/空间覆盖类 | 最短路覆盖、最近设施分配、空间距离统计 | p-median、p-center、最大覆盖、网络流 | 覆盖率、响应时间、连通性、负载差异 |
| 动态调度类 | 离散事件仿真、贪心规则、固定优先级 | 滚动优化、遗传算法调度、仿真优化 | 吞吐量、等待时间、利用率、事件日志一致性 |
| 机理拟合类 | 经验曲线拟合、最小二乘、残差分析 | 微分方程、非线性参数估计、物理约束优化 | MAE、RMSE、R²、参数物理合理性 |
| 分类聚类类 | KMeans、层次聚类、决策树 baseline | 随机森林、SVM、集成学习、聚类稳定性 | accuracy、F1、AUC、轮廓系数 |
| 多目标决策类 | 加权和 baseline、规则型折中方案 | Pareto 分析、ε 约束法、多目标遗传算法 | 目标值、约束满足率、权重敏感性 |
| 混合型问题 | 分问题题型分解、最小子问题闭环 | 预测加优化、评价加调度、空间聚类加优化 | 子模型指标、证据链、输出契约、阶段边界 |

## 3. 只能做 PARTIAL_MODEL_ONLY 的情况

1. 关键约束缺失，例如目标函数、容量、预算、时间边界或物理边界条件缺失。
2. 关键字段无法确认，例如坐标、价格、完成标签、需求量或类别标签无法映射。
3. 原始数据可读但题面目标不完整。
4. 只能完成某一子问题的最小闭环，无法覆盖全题。
5. 机理拟合缺少必要物理参数，只能做曲线拟合或局部解释。

## 4. 必须缺约束安全终止的情况

1. 优化目标无法定义。
2. 决策变量和约束无法建立。
3. 数据附件缺失或核心表无法解析。
4. 题面要求输出正式表格，但模板结构无法确认。
5. 关键单位或时间边界缺失且无法合理假设。

## 5. 不能把 baseline 写成全局最优的情况

1. 启发式、贪心规则、最近邻分配、综合评分、logistic baseline、KMeans 聚类均不能写成全局最优。
2. 未证明凸性或未完成全局搜索时，非线性优化不能写成全局最优。
3. 预测模型只给预测完成率或趋势，不能写成真实发生结果。
4. 评价排序只是指标体系下的结果，不能写成唯一客观真值。

## 6. 必须进入人工 gate 的情况

1. 题型路由完成后，需要人工确认主题型和辅助题型。
2. 模型路线选择前，需要人工确认 baseline 与 advanced 的取舍。
3. 结果生成后，需要人工确认数值一致性、证据链和边界。
4. 论文草稿或展示材料生成前，需要人工确认结论口径。
5. 正式比赛披露前，需要人工确认 AI 使用记录模式。
