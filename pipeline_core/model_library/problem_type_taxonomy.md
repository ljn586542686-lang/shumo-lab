# 题型分类体系

状态：`PASS_WITH_LIMITATION / PROBLEM_ROUTING_MODEL_LIBRARY_BASELINE_READY`

用途：为新赛题进入 `active_competition/current_case` 后的题型路由、模型路线选择、验证计划和论文结构设计提供统一分类口径。本文件不是自动套模板规则，低置信度或混合题必须进入人工确认。

## 1. 统计分析类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 规律、影响因素、相关性、差异、原因分析、统计特征、显著性 |
| 常见数据形式 | 横截面表格、历史记录、分类标签、价格/数量/评分字段、空间或时间附加字段 |
| 常见建模目标 | 描述规律、解释差异、识别影响因素、建立 baseline 解释模型 |
| 常见约束 | 缺失值处理、异常值披露、分组口径、变量可解释性 |
| 常见输出 | 统计汇总表、分组对比表、相关性表、解释模型指标、原因分析 |
| 常见风险 | 相关性写成因果、样本偏差未披露、异常值静默删除、统计结论外推 |
| 是否适合最小闭环 | 适合 |
| 是否需要人工确认 | 需要确认关键字段、异常值处理和结论边界 |

## 2. 预测时间序列类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 预测、未来若干期、时间序列、趋势、波动、动态预测 |
| 常见数据形式 | 按日/周/月采样序列、多变量历史表、滚动窗口数据 |
| 常见建模目标 | 预测未来值、评估误差、给出区间或趋势判断 |
| 常见约束 | 时间顺序不可打乱、训练验证分割、外推边界、缺失时点处理 |
| 常见输出 | 预测表、误差指标、残差分析、滚动验证结果 |
| 常见风险 | 数据泄漏、过拟合、把预测写成真实结果、忽略突变和政策因素 |
| 是否适合最小闭环 | 适合，可从移动平均或 ARIMA baseline 开始 |
| 是否需要人工确认 | 需要确认采样频率、预测目标和评价指标 |

## 3. 优化规划类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 最优、最大化、最小化、分配、计划、约束、成本、收益、资源 |
| 常见数据形式 | 参数表、容量表、成本表、需求表、候选方案表 |
| 常见建模目标 | 构造目标函数，满足约束，输出可行方案或优化方案 |
| 常见约束 | 预算、容量、时间、整数性、上下界、供需平衡、逻辑约束 |
| 常见输出 | 决策变量表、目标函数值、约束满足情况、方案对比 |
| 常见风险 | 约束缺失仍求解、不可行未诊断、启发式写成全局最优 |
| 是否适合最小闭环 | 适合，但必须先做约束完整性检查 |
| 是否需要人工确认 | 必须确认目标函数、约束和可行性口径 |

## 4. 评价决策类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 评价、排序、重要性、综合指标、优劣、选择、决策 |
| 常见数据形式 | 多指标表、评分表、等级表、专家判断矩阵 |
| 常见建模目标 | 构建指标体系，计算权重，排序或分级 |
| 常见约束 | 指标方向、权重来源、一致性、缺失指标处理 |
| 常见输出 | 指标权重、综合得分、排序、稳定性分析 |
| 常见风险 | 主观权重未披露、评分写成客观真值、排序不稳定 |
| 是否适合最小闭环 | 适合，可从综合评分或 TOPSIS baseline 开始 |
| 是否需要人工确认 | 需要确认指标方向和权重解释 |

## 5. 图网络/空间覆盖类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 路网、节点、边、覆盖、最短路、选址、服务范围、空间距离 |
| 常见数据形式 | 节点坐标、道路边、距离矩阵、设施位置、需求点 |
| 常见建模目标 | 计算可达性、覆盖率、设施负载、选址或路径方案 |
| 常见约束 | 距离单位、边权来源、连通性、服务半径、容量 |
| 常见输出 | 节点分配、覆盖率、响应时间、选址方案、网络指标 |
| 常见风险 | 坐标距离替代真实道路距离未披露、孤立节点未处理、覆盖结论政策化 |
| 是否适合最小闭环 | 适合，可从最短路覆盖 baseline 开始 |
| 是否需要人工确认 | 需要确认边权、速度、覆盖阈值和坐标单位 |

## 6. 动态调度类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 调度、动态、工序、设备、排队、等待、吞吐、仿真 |
| 常见数据形式 | 设备参数、处理时间、移动时间、事件日志、班次边界 |
| 常见建模目标 | 设计调度规则，计算吞吐量、等待时间和利用率 |
| 常见约束 | 设备容量、工序顺序、时间窗口、故障、资源冲突 |
| 常见输出 | 事件日志、调度表、吞吐量、等待时间、利用率 |
| 常见风险 | 简单规则写成最优、事件时间口径不一致、未处理故障却宣称完整 |
| 是否适合最小闭环 | 适合，可从离散事件仿真 baseline 开始 |
| 是否需要人工确认 | 需要确认工序范围、故障假设和统计口径 |

## 7. 机理拟合类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 机理、物理过程、曲线、参数估计、拟合、热传导、动力学 |
| 常见数据形式 | 实验曲线、时间序列测量值、物理参数、边界条件 |
| 常见建模目标 | 建立机理方程，估计参数，解释曲线和误差 |
| 常见约束 | 物理单位、边界条件、参数范围、实验条件 |
| 常见输出 | 参数估计、拟合曲线、误差指标、残差图 |
| 常见风险 | 缺物理约束仍外推、拟合好写成机理正确、单位不一致 |
| 是否适合最小闭环 | 部分适合，缺约束时只能 `PARTIAL_MODEL_ONLY` |
| 是否需要人工确认 | 必须确认物理假设、边界条件和适用范围 |

## 8. 分类聚类类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 分类、聚类、识别、判别、分组、类别、未知样本 |
| 常见数据形式 | 特征矩阵、标签、成分数据、样本属性表 |
| 常见建模目标 | 给样本分类、发现群组、解释特征贡献 |
| 常见约束 | 标签可靠性、类别不平衡、特征尺度、缺失值处理 |
| 常见输出 | 分类结果、聚类标签、混淆矩阵、特征重要性 |
| 常见风险 | 聚类标签过度解释、训练测试泄漏、样本量不足 |
| 是否适合最小闭环 | 适合，可从 KMeans 或决策树 baseline 开始 |
| 是否需要人工确认 | 需要确认标签定义、特征处理和评价指标 |

## 9. 多目标决策类

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 多目标、权衡、成本与效果、效率与公平、收益与风险 |
| 常见数据形式 | 多目标参数表、候选方案、约束表、评价指标表 |
| 常见建模目标 | 构造权衡机制，输出 Pareto 或加权方案 |
| 常见约束 | 权重设定、目标冲突、约束可行性、决策偏好 |
| 常见输出 | 权重方案、Pareto 方案、折中方案、敏感性分析 |
| 常见风险 | 权重主观性未披露、单一加权写成唯一最优 |
| 是否适合最小闭环 | 适合，但需先定义可解释 baseline |
| 是否需要人工确认 | 必须确认目标优先级和权重解释 |

## 10. 混合型问题

| 项目 | 内容 |
|---|---|
| 典型题面关键词 | 多问递进、评价加优化、预测加决策、空间加定价、调度加仿真 |
| 常见数据形式 | 多附件、多表、多阶段结果、历史数据加未来任务 |
| 常见建模目标 | 分阶段建立多个子模型，形成最小闭环和扩展路线 |
| 常见约束 | 子问题依赖、输出衔接、数据口径一致、人工 gate |
| 常见输出 | 分问题报告、模型路线图、子模型结果、证据链 |
| 常见风险 | 单一路由覆盖全题、前一问结论未经验证直接用于后一问 |
| 是否适合最小闭环 | 适合，但只做最小子问题闭环 |
| 是否需要人工确认 | 必须确认主题型、辅助题型和阶段边界 |
