# 展示层质量门规则

状态：`PASS_WITH_LIMITATION / SHOWCASE_QUALITY_GATE_UPGRADED`

## 1. 目的

展示层质量门用于检查展示包、展示版 PDF、图表、表格、README、meta 报告和 AI 使用记录是否适合给老师、队员和训练场景查看。该质量门只做检查，不修改模型结果，不授权 `final_submit/`。

## 2. 图表中文化规则

1. 图表标题、坐标轴、图例默认使用中文。
2. 必要术语可以保留英文缩写，例如 `AUC`、`CSV`、`JSON`、`baseline`、`DRAFT_ONLY`、`NOT_FOR_FINAL_SUBMISSION`。
3. 如果图表生成脚本中仍存在明显英文标题、英文坐标轴或英文图例，应标记为 `MEDIUM_RISK`。
4. 不能为了中文化图表而修改统计结论或模型输出。

## 3. 表格中文展示版规则

1. `output/tables/` 中的原始机器 CSV 可以保留英文字段名。
2. 进入展示阶段后，必须另行生成 `output/tables_showcase/` 中文展示表。
3. 展示包应包含中文展示 Excel，例如 `2017B_showcase_tables.xlsx`。
4. 展示表缺失时，标记为 `MEDIUM_RISK`。
5. 不得覆盖、删除或静默修改原始机器 CSV。

## 4. README 与 meta 报告规则

1. 面向人阅读的 README、meta 报告、展示说明和交接说明默认中文。
2. 当前 active case 已接入真实赛题后，README 不得停留在空模板状态。
3. 如果 README 仍显示 `TEMPLATE_ONLY` 或 `NOT_READY_FOR_MODELING`，标记为 `HIGH_RISK`。
4. 状态码、路径、变量名、文件名可以保留英文。

## 5. AI 使用记录双模式规则

AI 使用记录分为两种模式：

1. `showcase_mode`：校内展示模式，用于老师沟通、队员交流、暑假训练、选拔展示和阶段性成果展示包。该模式使用“智能辅助工具”“AI 辅助工具”“辅助建模工具”等概括表述，不写具体 AI 名称，不写具体模型名，不展示长提示内容、对话全文和内部实现细节。
2. `official_submission_mode`：正式比赛披露模式，用于正式比赛论文、正式提交附件、AI 使用声明、参考文献后的 AI 工具说明和组委会要求提交的 AI 使用记录。该模式必须按照当年竞赛规则清楚披露 AI 工具名称、版本/型号、开发机构/公司、使用日期、使用环节、生成或辅助内容、人工复核方式，以及队员独立完成核心建模与分析的说明。

风险判定：

1. `showcase_mode` 中出现具体 AI 名称、具体模型名、长提示内容或对话全文，标记为 `HIGH_RISK`。
2. `official_submission_mode` 中故意用泛化表述替代具体工具名，或缺少工具名称、版本/型号、使用范围和人工校验方式，标记为 `HIGH_RISK`。
3. 当前 2017B 展示包属于 `showcase_mode`。

## 6. 结论边界规则

1. 阶段性成果不得写成完整赛题结论。
2. baseline 方案不得写成已证明最优的方案。
3. 预测完成率不得写成实际完成率。
4. 问题1/问题2阶段成果不得误写为已经覆盖问题3/问题4。
5. 如果出现结论越界，标记为 `HIGH_RISK`。

## 7. 安全项规则

1. `final_submit/` 不得存在。
2. `final_submit_allowed` 必须为 `false`。
3. human_review gate 不得自动通过。
4. 不得写入人工批准标记。
5. 展示版 PDF 只允许作为展示材料，不得作为比赛提交材料。

## 8. 展示不篡改原则

展示层只改变呈现方式，不改变数据、代码、模型输出、统计结论、图表含义或机器 CSV。
