# AI 使用记录双模式规则

状态：`PASS_WITH_LIMITATION / AI_DISCLOSURE_DUAL_MODE_READY`

## 1. 规则目的

AI 使用记录不能只有一种口径。校内展示材料需要保护展示边界，避免暴露具体工具、长提示内容和内部实现细节；正式比赛材料则必须按照当年竞赛规则、学校要求和组委会要求进行透明披露，不能故意模糊。

因此，生产线采用两种模式：

1. `showcase_mode`：校内展示模式。
2. `official_submission_mode`：正式比赛披露模式。

## 2. 校内展示模式：showcase_mode

适用场景：

1. 老师沟通。
2. 队员交流。
3. 暑假训练。
4. 选拔展示。
5. 阶段性成果展示包。
6. `2017B_stage_showcase_revised.pdf`。

要求：

1. 使用“智能辅助工具”“AI 辅助工具”“辅助建模工具”“智能化文本与代码辅助工具”等概括表述。
2. 不写具体 AI 名称。
3. 不写具体模型名。
4. 不展示长提示内容。
5. 不展示对话全文。
6. 不展示内部实现细节。

风险判定：

1. 校内展示材料出现具体 AI 名称：`HIGH_RISK`。
2. 校内展示材料出现具体模型名：`HIGH_RISK`。
3. 校内展示材料出现长提示内容或对话全文：`HIGH_RISK`。
4. 校内展示材料暴露内部实现细节：`HIGH_RISK`。

## 3. 正式比赛披露模式：official_submission_mode

适用场景：

1. 正式比赛论文。
2. 正式提交附件。
3. AI 使用声明。
4. 参考文献后的 AI 工具说明。
5. 组委会要求提交的 AI 使用记录。

要求：

必须按照当年竞赛规则和学校/组委会要求披露，至少包括：

1. AI 工具名称。
2. 版本/型号。
3. 开发机构/公司。
4. 使用日期。
5. 使用环节。
6. 生成或辅助内容。
7. 人工复核方式。
8. 队员独立完成核心建模与分析的说明。

风险判定：

1. 正式比赛披露材料没有写清 AI 工具名称：`HIGH_RISK`。
2. 正式比赛披露材料没有写清版本/型号：`HIGH_RISK`。
3. 正式比赛披露材料没有写清使用范围：`HIGH_RISK`。
4. 正式比赛披露材料没有写清人工校验方式：`HIGH_RISK`。
5. 正式比赛披露材料故意用“智能辅助工具”等泛化表述替代具体工具名：`HIGH_RISK`。

## 4. 当前 2017B 口径

当前 2017B 展示包和 `2017B_stage_showcase_revised.pdf` 属于 `showcase_mode`。因此当前展示包继续使用泛化表述，不需要修改 PDF，也不需要重生成展示材料。

如果后续进入正式比赛论文或正式提交材料阶段，必须切换到 `official_submission_mode`，并按当年规则完整披露。
