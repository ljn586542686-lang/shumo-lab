# 图表展示风格指南

状态：`PASS_WITH_LIMITATION / SHOWCASE_QUALITY_GATE_UPGRADED`

## 1. 标题

标题应简短、中文、直接说明图表内容。例如：

1. 任务定价分布。
2. 完成与未完成任务定价对比。
3. 原方案与新方案预测完成率对比。
4. 定价方案敏感性分析。

## 2. 坐标轴

坐标轴应包含中文变量名和必要单位。例如：

1. 经度。
2. 纬度。
3. 任务定价。
4. 任务数量。
5. 预测完成率。
6. 价格增幅。
7. 最近会员距离（km）。
8. 附近会员数量（3 km）。

## 3. 图例

图例应使用中文分组名。例如：

1. 已完成任务。
2. 未完成任务。
3. 原方案。
4. 新方案。
5. 保守方案。
6. 均衡方案。
7. 激进方案。

## 4. 图注

图注应说明：

1. 数据来源。
2. 计算口径。
3. 预测值与实际值的区别。
4. baseline 只是基准口径。
5. 异常数据处理边界。

## 5. 展示包建议

展示包优先选择 4 到 8 张高信息密度图表。每张图应回答一个明确问题，并能追溯到输出表或验证报告。
