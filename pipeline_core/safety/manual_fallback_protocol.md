# 人工兜底流程

当前状态：`PASS_WITH_LIMITATION / COMPETITION_RED_TEAM_CONTINGENCY_READY`

本流程用于 AI 工具、Codex、runner 或自动脚本不可用时，确保队伍仍能完成最低可交付的数学建模成果。

## 1. 触发条件

出现以下任一情况时进入人工兜底：

1. AI/Codex 无法稳定使用超过 30 分钟；
2. 题型路由结果明显错误且无法修复；
3. 模型代码无法运行且时间不足；
4. PDF/Word/LaTeX 输出失败；
5. `final_submit/` 或 gate 出现异常风险；
6. 距提交不足 3 小时且自动流程仍未形成稳定结果。

## 2. 人工审题

人工完成：

1. 逐题列出任务；
2. 标出目标函数、约束、输出要求；
3. 识别数据来源；
4. 记录无法确认的题面信息；
5. 形成一页问题清单。

可参考：

- `pipeline_core/model_library/`
- `pipeline_core/literature_library/knowledge_cards/`
- `pipeline_core/paper_quality/problem_analysis_quality_rules.md`

## 3. Excel 数据审计

人工完成：

1. 打开附件；
2. 记录 sheet、字段、行列数；
3. 标记缺失值、异常值、单位；
4. 保留 raw 文件不修改；
5. 如需清洗，在副本或 processed 表中处理并记录。

## 4. Python/MATLAB 最小模型

最低要求：

1. 只做一个核心问题的 baseline；
2. 优先选择描述统计、线性/Logistic 回归、简单优化、图论最短路或可解释评价模型；
3. 生成 result summary；
4. 生成至少一张图或一张表；
5. 写清模型边界。

## 5. 手工绘图

自动图表失败时：

1. 用 Excel 生成基础图；
2. 标题、坐标轴、图例使用中文；
3. 图注写清数据来源；
4. 不篡改数值。

## 6. Word/LaTeX 论文

人工写作优先级：

1. 摘要；
2. 问题分析；
3. 模型假设；
4. 模型建立；
5. 结果分析；
6. 灵敏度或验证；
7. 局限性；
8. 参考文献；
9. AI 使用披露。

## 7. 手动引用

若文献工具不可用：

1. 使用本地已确认文献；
2. 不编造作者、期刊、年份、DOI；
3. 无法确认的文献先列为待补充；
4. 正式提交前必须人工核验。

## 8. 手动 final_submit 检查

`final_submit/` 只能人工准备。准备前必须检查：

1. 正式论文 PDF 可打开；
2. 提交附件存在；
3. AI 使用披露完整；
4. 引用和证据链可追溯；
5. gate_4 人工确认；
6. 队长明确授权。

## 9. 最低可交付版本

最低可交付版本必须包含：

1. 问题分析；
2. 一个可解释 baseline；
3. 一组核心结果；
4. 一组图表；
5. 验证或敏感性说明；
6. 局限性；
7. AI 使用披露；
8. 参考文献或引用缺口说明。

该版本不追求复杂模型，但必须真实、可解释、可复核。
