# 分问题叙事升级规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_DEEP_STRUCTURE_BLOCKED_NEEDS_MANUAL_REVIEW`

## 1. 规则目标

本规则用于改进数学建模论文中多问之间的叙事递进。当前规则来自 L3.2a 框架级结构吸收和 L3.2a-plus 的 blocked 人工阅读任务，不包含优秀论文正文原句。

## 2. 分问题叙事基本链路

每个子问题应按以下顺序组织：

1. 题面目标转化：说明该问要解决什么可计算任务。
2. 输入与约束：说明使用哪些数据、变量和题面约束。
3. 方法选择：说明为什么选择该模型或 baseline。
4. 模型建立：给出变量、指标、目标或计算规则。
5. 求解或计算：说明算法流程和参数。
6. 结果展示：连接输出表、图和摘要指标。
7. 验证与敏感性：说明数值复核、稳健性或异常数据影响。
8. 结论边界：说明当前结论不能覆盖哪些范围。

## 3. 多问递进规则

1. 问题1通常承担数据审计、统计规律、基础评价或初始 baseline。
2. 问题2通常在问题1基础上进行优化、改进、预测或方案比较。
3. 问题3通常引入附加约束、打包策略、转运调度、成本控制或不确定性。
4. 问题4通常面向新数据、推广场景、全局评价或实施效果。
5. 若只完成部分问题，必须显式写出未覆盖范围。

## 4. 证据链要求

每个子问题至少需要：

1. 一个输入来源说明。
2. 一个核心计算或建模文件。
3. 一个结果表或图。
4. 一个验证或复核文件。
5. 一个结论边界说明。

## 5. 禁止叙事

禁止：

1. 把问题1/2阶段成果写成完整解决赛题。
2. 把预测完成率写成真实完成率。
3. 把 baseline 定价、启发式调度或近似覆盖写成全局最优。
4. 把未处理的问题写成已完成。
5. 用优秀论文样本替代当前赛题证据。
