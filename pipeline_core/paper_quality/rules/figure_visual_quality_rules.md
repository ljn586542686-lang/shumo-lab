# 图表视觉质量规则

状态：`DRAFT_ONLY / NOT_FOR_OFFICIAL_SUBMISSION`

## 1. 目的

本规则用于防止论文、展示稿和提交格式候选版中出现黑底图、低分辨率图、字号过小、坐标轴不可读、图注工程化等问题。图表视觉修复只能改善展示与排版质量，不得修改模型数值、实验结论或证据链。

## 2. 适用范围

- 当前 case 的 `output/figures/`；
- 论文 Markdown / TeX 中引用的图像；
- 展示版 PDF、评测版 PDF、submit candidate PDF；
- 进入 PPT 或展示包的图像。

临时调试截图不得进入论文正文。若临时截图必须保留，只能放在调试日志或 reports 中，并明确不作为论文图。

## 3. 必须阻断的图表问题

以下任一情况出现时，禁止进入正式化流程：

1. 黑底图、灰黑底图或 MATLAB 深色主题截图；
2. 坐标轴、刻度、标题、图例文字不可读；
3. 字号明显过小，论文打印后无法辨认；
4. 图片分辨率不足，放入 PDF 后发虚；
5. 图表宽高比例严重不适合论文页面；
6. 图表在 PDF 中过大、过小、撑满页面或遮挡页码；
7. 图注只写文件路径、代码路径或“来源：output/figures/xxx.png”，没有论文式解释；
8. 图表经过重绘后改变了模型数值、数据含义或结论边界。

## 4. 建议通过条件

| 项目 | 建议标准 |
|---|---|
| 背景 | 白色或接近白色 |
| 坐标轴与文字 | 黑色或深色高对比色 |
| 标题、坐标轴、图例字号 | 不低于 12 pt，或 PDF 打印后清晰可读 |
| 线宽 | 不低于 1.5 |
| 导出分辨率 | 不低于 300 dpi |
| TeX 插图宽度 | 通常为 `0.65\textwidth` 至 `0.80\textwidth` |
| 图注 | 说明变量关系、比较对象和图表用途 |
| PDF 目检 | 人工确认无黑底、无压图、无不可读坐标轴 |

## 5. 自动检查建议

自动化质量门可优先做以下检查：

- 读取图片宽高、dpi 和文件大小；
- 抽样图片角点、边缘或背景亮度，标记黑底风险；
- 检查 TeX 中 `\includegraphics` 宽度是否超过 `0.85\textwidth` 或 `0.85\linewidth`；
- 扫描图注中是否出现大量 `output/figures/`、`.png`、`.csv`、`.json`；
- 读取 PDF 编译日志中的 missing figure、Overfull box 和 float warning；
- 对核心图执行人工目检清单。

## 6. 人工目检项

自动检查不能完全替代人工目检。以下内容必须人工确认：

- 图中文字是否能在 100% PDF 缩放下读清；
- 多线图是否挤在一起；
- 图例是否遮挡主图；
- 图表与正文解释是否对应；
- 图表是否被分页切断或靠近页脚；
- 图注是否像论文图注，而不是工程文件说明。

## 7. 修复原则

1. 只允许修复视觉样式，不得改模型、数据、数值和结论。
2. 重绘图必须来自已有处理数据、模型输出表或已确认结果。
3. 不得为了图表好看删掉异常点或不利结果。
4. 不得把模型预测图写成实验真实结果图。
5. 图表修复后必须重新检查 PDF 版式。
6. 若 PDF 编译工具不可用，不得伪造 PDF 成功。

- `PASS_WITH_LIMITATION / FIGURE_VISUAL_QUALITY_READY_PDF_PENDING`
- `BLOCKED / FIGURE_VISUAL_QUALITY_FAILED`
