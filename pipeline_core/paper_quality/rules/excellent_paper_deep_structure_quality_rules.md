# 优秀论文正文级结构质量规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_DEEP_STRUCTURE_BLOCKED_NEEDS_MANUAL_REVIEW`

## 1. 目的

本规则用于控制后续优秀论文正文级结构抽取，防止正文抽取演变为原文复写、引用伪造或论文代写。

## 2. 正文级抽取前置条件

必须满足至少一项：

1. 本地有可用 PDF 文本解析器。
2. 用户提供可复制的 PDF 文本。
3. 用户提供关键页面截图并允许人工结构标注。
4. 人工完成逐页阅读并记录结构标签。

当前以上条件未满足，因此正文级抽取保持 blocked。

## 3. 抽取字段

允许记录：

1. 摘要结构。
2. 问题重述组织。
3. 子问题拆解方式。
4. 模型假设数量与功能类别。
5. 符号说明是否服务公式。
6. 模型建立顺序。
7. 算法和求解流程表达层级。
8. 图表证据链组织方式。
9. 结果解释方式。
10. 灵敏度分析、误差分析和模型检验是否存在。
11. 优缺点评价位置。
12. 多问递进关系。

## 4. 禁止记录

禁止记录：

1. 原文句子。
2. 原文段落。
3. 具体图表内容。
4. 具体数值结论。
5. 同题解法细节。
6. 参考文献条目。
7. 可直接提交的论文段落。

## 5. 质量检查规则

每条结构抽取结果必须检查：

1. 是否包含原文句式。
2. 是否包含具体赛题结论。
3. 是否被误写为正式 citation。
4. 是否被误写为方法理论依据。
5. 是否会把 baseline 或 heuristic 夸大为全局最优。
6. 是否有人工复核状态。

若任一项违规，必须标记为 `BLOCKED / EXCELLENT_PAPER_DEEP_ABSORPTION_SAFETY_VIOLATION`。
