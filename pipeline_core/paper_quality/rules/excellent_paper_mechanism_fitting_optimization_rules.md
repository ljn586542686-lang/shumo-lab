# 优秀论文启发的机理-拟合-优化规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_DEEP_STRUCTURE_RULES_INTEGRATED`

## 1. 来源边界

本规则来自人工辅助结构吸收结论，对应代表样本为 2020A 回焊炉温曲线优化控制。规则只吸收机理题的结构链路，不复制原文，不复写句式，不生成正式论文或引用。

## 2. 适用题型

适用于机理建模、过程控制、参数拟合、曲线拟合、物理过程仿真、工艺优化和多目标工艺参数设计类问题。

## 3. 固化规则

1. 机理题应先建立过程模型，再拟合参数，再进行优化。
2. 工艺约束必须拆成可检查边界，例如温度范围、速度范围、时间窗口、斜率限制、误差阈值或安全边界。
3. 参数拟合后必须回代验证，不能只报告拟合参数。
4. 多目标工艺优化必须说明加权、分层、约束转化或目标转化方式。
5. 误差分析必须区分观测误差、模型误差、离散化误差和参数不确定性。
6. 若模型使用简化机理，必须写明简化条件和可能影响。
7. 结果必须报告约束满足情况和工艺指标，不得只报告目标函数值。

## 4. 生产线调用说明

|模块|调用要求|
|---|---|
|`paper_outline_generator`|机理题目录必须按“过程模型-参数拟合-回代验证-工艺优化”组织|
|`problem_type_router`|识别曲线、过程、机理、拟合、控制、工艺参数、多目标工艺优化时挂接本规则|
|`evidence_chain_builder`|参数、拟合数据、回代验证图和优化结果必须建立追溯关系|
|`abstract_generator`|摘要必须同时说明机理模型、拟合验证和优化结果边界|
|`model_assumption_checker`|检查简化机理、边界条件、参数恒定性和数据采样假设|
|`sensitivity_analysis_gate`|检查关键参数、时间步长、误差阈值、权重和工艺约束扰动|
|`limitation_and_validation_writer`|写明拟合误差、简化模型和多目标权重主观性|
|`final_human_review_gate`|阻断“拟合好即真实机理”“多目标权重唯一正确”等表述|

## 5. 禁止项

1. 不得拟合后不回代验证。
2. 不得把工艺约束写成不可检查的口号。
3. 不得把多目标加权结果写成唯一最优。
4. 不得忽略模型简化和参数不确定性。
