# 优秀论文启发的统计类证据链规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_DEEP_STRUCTURE_RULES_INTEGRATED`

## 1. 来源边界

本规则来自人工辅助结构吸收结论，对应代表样本为 2022C 古代玻璃分类分析。规则只吸收统计类论文结构和证据链组织，不复制原文，不复写句式，不生成正式 citation。

## 2. 适用题型

适用于统计分析、分类、聚类、综合评价、成分数据分析、比例数据分析、相关性分析和变量关系解释类问题。

## 3. 固化规则

1. 统计类题目必须先建立数据质量处理层，包括字段解释、缺失值、异常值、重复值、量纲和样本边界。
2. 成分数据、比例数据必须考虑归一化、闭合约束、总量约束或比例和为 1 的结构风险。
3. 统计建模必须形成“描述统计、统计检验、模型建立、模型评价、稳定性分析”的闭环。
4. 变量关系必须解释，不得只堆模型名称和指标。
5. 分类或聚类模型必须配套评价指标、可解释性分析或稳定性检查。
6. 相关性、差异检验和分类结果不得写成因果结论。
7. 输出图表必须能追溯到输入字段、处理口径和代码。

## 4. 生产线调用说明

|模块|调用要求|
|---|---|
|`paper_outline_generator`|统计类目录必须包含数据质量层、描述统计、模型评价和稳定性分析|
|`problem_type_router`|识别分类、聚类、评价、成分、比例、相关性关键词时挂接本规则|
|`evidence_chain_builder`|每个统计结论必须绑定字段、输出表、图和验证报告|
|`abstract_generator`|摘要必须写明样本规模、数据处理、核心统计发现和评价指标|
|`model_assumption_checker`|检查归一化、缺失值、异常值、成分约束是否被披露|
|`sensitivity_analysis_gate`|检查异常样本、特征选择、阈值、聚类数或评价权重扰动|
|`limitation_and_validation_writer`|写明相关性不等于因果、样本偏差和模型稳定性限制|
|`final_human_review_gate`|阻断“变量必然导致”“分类绝对正确”等越界表述|

## 5. 禁止项

1. 不得只堆模型而不解释变量关系。
2. 不得把相关性写成因果关系。
3. 不得把分类或聚类结果写成唯一客观真值。
4. 不得忽略成分数据或比例数据的结构约束。
