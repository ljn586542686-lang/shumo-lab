# 优秀论文启发的统计-优化决策链规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_DEEP_STRUCTURE_RULES_INTEGRATED`

## 1. 来源边界

本规则来自人工辅助结构吸收结论，对应代表样本为 2020C 中小微企业信贷决策。规则只吸收“评分/预测到优化决策”的结构链路，不复制原文，不复写句式，不生成正式参考文献。

## 2. 适用题型

适用于统计预测与优化决策结合的 mixed_problem，例如风险评分、完成概率预测、客户评价、供应商评分、信用评估、价格优化、资源配置和策略制定。

## 3. 固化规则

1. mixed_problem 必须拆成预测评分层和优化决策层。
2. 预测概率、风险评分、分类结果只能作为优化模型输入，不得写成真实结果。
3. 结果部分必须同时报告预测模型评价和优化决策结果。
4. 情景变化应通过风险修正系数、场景参数、约束变化或目标权重变化进入优化模型。
5. 优化模型必须说明预测误差如何影响决策可信度。
6. 方案比较必须同时展示收益、成本、风险和约束满足情况。
7. 如果使用 baseline 定价或启发式规则，应明确不是全局最优。

## 4. 生产线调用说明

|模块|调用要求|
|---|---|
|`paper_outline_generator`|混合题目录必须拆成“预测/评分层”和“优化/决策层”|
|`problem_type_router`|识别预测+优化、评分+决策、概率+定价、风险+资源配置时挂接本规则|
|`evidence_chain_builder`|预测输出进入优化输入时必须记录字段转换和误差边界|
|`abstract_generator`|摘要必须同时报告预测评价指标和优化方案指标|
|`model_assumption_checker`|检查预测值、风险评分、分类标签进入优化模型的假设|
|`sensitivity_analysis_gate`|检查风险修正系数、场景参数、权重和约束变化|
|`limitation_and_validation_writer`|必须写明预测概率不等于真实概率，预测完成率不等于实际完成率|
|`final_human_review_gate`|阻断“预测结果即真实结果”“baseline 方案即最优方案”等表述|

## 5. 禁止项

1. 不得把预测概率、预测风险、预测完成率写成真实结果。
2. 不得只报告优化结果而不报告预测模型评价。
3. 不得忽略预测误差对优化决策的影响。
4. 不得把同题信贷决策路线固化为所有 mixed_problem 的唯一模板。
