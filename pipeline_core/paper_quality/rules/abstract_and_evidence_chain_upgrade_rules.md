# 摘要与证据链升级规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_STRUCTURE_ABSORPTION_READY`

## 1. 规则目标

本规则把优秀论文结构样本的可复用组织规律转化为摘要生成和证据链检查要求。规则不使用优秀论文原文，不生成正式论文段落，不生成真实参考文献。

## 2. 摘要质量规则

摘要应按以下功能块组织：

1. 问题范围：说明当前覆盖哪些子问题，不覆盖哪些子问题。
2. 数据基础：说明数据来源、样本规模、关键字段和异常处理边界。
3. 方法路线：说明使用的统计、优化、评价、图网络、仿真或混合路线。
4. 核心结果：只写已经由输出表、图和验证报告支撑的数值。
5. 验证与敏感性：说明复核、稳健性或小压测结果。
6. 结论边界：说明 baseline、heuristic、预测误差、近似和未完成范围。

禁止：

1. 不得使用优秀论文原句。
2. 不得写未运行出的结果。
3. 不得把阶段性成果写成完整正式论文。
4. 不得把预测完成率写成真实完成率。
5. 不得把启发式或 baseline 写成全局最优。

## 3. 证据链质量规则

每条结论必须绑定至少一种当前赛题证据：

1. 原始数据或标准化数据。
2. 代码文件。
3. 输出表。
4. 输出图。
5. 验证报告。
6. 人工复核门。
7. 文献或知识卡支撑，但仅限方法背景和理论边界，不得替代数据证据。

## 4. 图表证据链规则

每张图表必须记录：

1. 数据来源。
2. 生成代码。
3. 关键字段。
4. 图表标题和图例。
5. 对应正文结论。
6. 是否为展示版。
7. 是否存在中文化要求。

## 5. 多问递进规则

对多问赛题，应建立以下链路：

1. 问题1：数据规律、基础评价或诊断。
2. 问题2：基于问题1的模型、优化或改进方案。
3. 问题3：扩展约束、打包、调度、成本或不确定性处理。
4. 问题4：新数据应用、推广、全局方案或实施效果评价。

如果当前只完成部分问题，摘要和结论必须显式写出未完成范围。

## 6. 人工复核要求

生成摘要或证据链前，必须检查：

1. 是否存在正式引用缺口。
2. 是否存在未验证结论。
3. 是否存在优秀论文结构样本被误写成理论支撑。
4. 是否存在 final_submit 风险。
5. 是否存在自动通过 human gate。
