# 表格版式质量规则

状态：`DRAFT_ONLY / NOT_FOR_OFFICIAL_SUBMISSION`

## 1. 目的

本规则用于防止论文表格出现超宽、断表、列名断字、模型名溢出和实验设计表不可读等问题。

## 2. 必须阻断的问题

1. 表格超出页面边界；
2. 列名被拆成不自然断字；
3. 过宽表硬塞正文；
4. 实验设计表跨页后不可读；
5. 模型比较表英文模型名过长导致溢出；
6. 表头断页后不重复；
7. 表格中混入大量文件路径、JSON key 或工程字段；
8. 表格数值被人为改写但无证据链。

## 3. 建议处理方式

| 问题 | 推荐处理 |
|---|---|
| 文本列过长 | 简表 + 分条说明 |
| 宽表溢出 | `tabularx`、`p{}` 固定列宽、拆表 |
| 长模型名 | 使用短名入表，表下注明完整名称 |
| 实验设计表过宽 | 只保留编号、条件、主要目的，理由写成条目 |
| 指标列过多 | 分成“核心指标表”和“补充指标表” |
| 正文不适合放大表 | 移至附录 |
| 数字过多 | 保留合理小数位，不改变数值含义 |

## 4. 通过条件

- 表格不超出页面；
- 列名完整、自然；
- 表格标题和表注清楚；
- 表格支持正文结论；
- 表格不替代必要解释；
- 宽表已拆分或移入附录；
- 所有关键数值可追溯。

## 5. 禁止事项

- 不得为了排版删除关键结果；
- 不得擅自改数值；
- 不得把模型预测写成实验结果；
- 不得把候选表格写成正式提交表格；
- 不得把 placeholder 或人工复核字段放入论文主体表格。

## 6. 状态码建议

- `PASS_WITH_LIMITATION / TABLE_LAYOUT_QUALITY_READY`
- `PASS_WITH_LIMITATION / TABLE_LAYOUT_REQUIRES_MANUAL_REVIEW`
- `BLOCKED / TABLE_LAYOUT_QUALITY_FAILED`
