# 优秀论文启发的多问优化题递进规则

当前状态：`PASS_WITH_LIMITATION / EXCELLENT_PAPER_DEEP_STRUCTURE_RULES_INTEGRATED`

## 1. 来源边界

本规则来自人工辅助结构吸收结论，对应代表样本为 2025A 无人机烟幕遮蔽策略优化。规则只吸收结构层规律，不复制原文，不复写句式，不生成正式论文，不作为方法理论 citation。

## 2. 适用题型

适用于多问优化题、调度题、资源配置题、多阶段决策题、多目标优化题，以及从基础模型逐步扩展到复杂协同模型的赛题。

## 3. 固化规则

1. 多问优化题必须建立问题关系图，说明每一问之间的依赖、扩展和输入输出关系。
2. 第 1 问应优先构造基础可验证模型，用于验证数据读取、目标定义、约束表达和求解流程。
3. 后续问题应逐步增加决策变量、约束、目标、不确定性、协同主体或场景扰动。
4. 每个扩展问题必须说明相对于上一问新增了什么，而不是重新套一个无关模型。
5. 启发式算法不得直接写成全局最优，必须配套验证、对照、枚举局部校验、敏感性分析或可行性检查。
6. 如果无法证明全局最优，只能写成 baseline、heuristic、可行方案、近似方案或当前求解器结果。
7. 结果部分必须同时报告目标值、约束满足情况、关键变量方案和验证边界。

## 4. 生产线调用说明

|模块|调用要求|
|---|---|
|`paper_outline_generator`|多问优化题自动生成“问题关系图”章节，并按基础模型、扩展模型、综合模型组织目录|
|`problem_type_router`|识别多问优化、调度、多目标、协同主体、不确定性关键词时，挂接本规则|
|`evidence_chain_builder`|每一问必须绑定输入、变量、约束、输出表和验证报告|
|`abstract_generator`|摘要不得直接写“全局最优”，应说明基础模型到复杂模型的递进和验证方式|
|`model_assumption_checker`|检查新增约束和新增主体是否有题面或数据来源|
|`sensitivity_analysis_gate`|启发式或多目标权重必须进入敏感性或对照检查|
|`limitation_and_validation_writer`|写明启发式、近似和未证明全局最优的边界|
|`final_human_review_gate`|阻断“全局最优”“最终最优方案”等无证明表述|

## 5. 禁止项

1. 不得固化同题具体解法。
2. 不得复制优秀论文原文结构图。
3. 不得把启发式算法写成全局最优。
4. 不得把某一年某一题的路线当成所有优化题模板。
