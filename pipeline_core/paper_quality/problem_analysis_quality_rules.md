# 问题分析质量规则

状态：`PASS_WITH_LIMITATION / PAPER_QUALITY_LAYER_BASELINE_READY`

## 检查项

1. 是否逐问对应题面。
2. 是否识别每个问题的数据来源。
3. 是否识别目标函数、评价目标或预测目标。
4. 是否识别约束条件和输出要求。
5. 是否识别缺失信息和人工确认项。
6. 是否区分主问题与子问题。
7. 混合型问题是否拆分为统计、优化、评价、预测、图网络、调度等子路线。

## 禁止内容

1. 漏掉题面问题。
2. 只按题目名称判断题型。
3. 忽略附件结构。
4. 把暂未处理的问题写成已完成。
5. 不说明 `PARTIAL_MODEL_ONLY` 或最小闭环边界。

## 输出建议

问题分析章节应包含“题型判断”“数据可用性”“目标与约束”“分问题建模路线”“未覆盖范围”五部分。
