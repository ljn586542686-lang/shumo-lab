# active_competition 论文质量层使用说明

状态：`PASS_WITH_LIMITATION / PAPER_QUALITY_LAYER_BASELINE_READY`

## 使用流程

1. 完成最小模型闭环。
2. 完成结果复核。
3. 建立或更新 `evidence_map.md`。
4. 队员根据已复核的结果撰写各章节，交给模板排版。当前文稿必须标记 `DRAFT_ONLY / NOT_FOR_FINAL_SUBMISSION`。
5. 使用论文质量层检查结构、证据链、公式、图表、引用和结论边界。
6. 进入人工 review gate。
7. 根据用途分流到 `showcase_mode` 或 `official_submission_mode`。
8. `final_submit/` 仍需人工授权和冻结流程。

## 进入条件

1. 已有 `result_summary`。
2. 已有输出表或输出图。
3. 已有 validation 报告。
4. 已有人工复核记录。
5. 已明确未覆盖问题。

## 禁止事项

1. 结果尚未核实时，相关结论必须等到复核后才能写入正式文稿。
2. 不把展示 PDF 当作正式论文。
3. 不跳过引用审计。
4. 不跳过 AI 使用披露。
5. 不自动创建 `final_submit/`。
