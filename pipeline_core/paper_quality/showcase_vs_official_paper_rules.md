# 展示版材料与正式比赛论文规则

状态：`PASS_WITH_LIMITATION / PAPER_QUALITY_LAYER_BASELINE_READY`

## 1. 展示版材料

展示版用于老师沟通、队员交流、暑假训练和选拔展示。

允许：

1. 适度简化模型细节。
2. 隐藏底层系统实现。
3. 使用 `showcase_mode` 模糊 AI 工具名。
4. 强调阶段性成果。
5. 使用展示表格和展示 PDF。

禁止：

1. 写成正式提交版本。
2. 创建 `final_submit/`。
3. 省略结论边界。
4. 展示完整提示词、完整对话或底层实现细节。

## 2. 正式比赛论文

正式比赛论文必须：

1. 完整响应题面。
2. 清楚披露 AI 使用。
3. 符合竞赛格式。
4. 有完整模型、结果、验证和结论。
5. 通过证据链、引用审计和输出契约验证。
6. 人工终审。
7. `final_submit/` 必须另走人工授权流程。

## 3. 分流原则

同一批结果可以用于展示版说明，但不能自动变成正式论文。正式论文必须重新经过论文质量层、人工 gate 和冻结流程。
