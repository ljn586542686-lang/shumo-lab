# 引用完整性规则

状态：`PASS_WITH_LIMITATION / PAPER_QUALITY_LAYER_BASELINE_READY`

## 必须规定

1. 不得伪造文献。
2. 不得把待检索文献写成已引用文献。
3. 不得伪造 DOI。
4. 不得伪造作者、期刊、年份、页码。
5. 如果没有本地论文原文，只能写“待检索”或“未发现本地支撑文献”。
6. 参考文献必须与正文内容相关。
7. AI 工具披露按 `showcase_mode` 与 `official_submission_mode` 区分。

## 检查项

1. 正文引用是否存在于 BibTeX 或文献清单。
2. 文献清单是否有正文未引用文献。
3. 每条引用是否真实支撑对应正文。
4. 是否存在装饰性引用。
5. 是否存在高级教材被用于支撑具体数值结论。
6. AI 使用是否被隐藏到普通文献中。

## 判定

| 判定 | 条件 |
|---|---|
| PASS | 引用完整且支撑关系明确 |
| WARNING | 有弱支撑、未引用文献或字段待补充 |
| FAIL | 有伪造、缺失或无法追溯引用 |
