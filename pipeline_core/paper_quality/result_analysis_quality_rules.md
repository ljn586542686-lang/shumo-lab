# 结果分析质量规则

状态：`PASS_WITH_LIMITATION / PAPER_QUALITY_LAYER_BASELINE_READY`

## 必须检查

1. 结果是否来自 `output/tables/`、`output/figures/` 或 `result_summary`。
2. 是否给出关键数值。
3. 是否解释数值含义。
4. 是否有图表支持。
5. 是否避免无证据结论。
6. 是否避免把相关性写成因果。
7. 是否避免把预测结果写成真实结果。
8. 是否说明异常值、缺失值和样本口径。

## 高风险表述

1. “证明该方案最优”，但没有数学证明或求解器证明。
2. “一定导致”，但只有相关性。
3. “完成率将达到”，但只是预测完成率。
4. “已完整解决”，但只完成部分问题。

## 结果写法要求

每个核心结果应写成：

1. 结果数值。
2. 来源文件。
3. 计算口径。
4. 解释。
5. 局限性。
