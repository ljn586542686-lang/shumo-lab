# 公式与符号质量规则

状态：`PASS_WITH_LIMITATION / PAPER_QUALITY_LAYER_BASELINE_READY`

## 必须检查

1. 每个公式变量是否定义。
2. 每个参数是否说明来源。
3. 单位是否说明。
4. 公式是否与模型一致。
5. 符号前后是否一致。
6. 缩写是否解释。
7. 经验公式是否被误写为严格定理。
8. 优化模型是否明确目标函数、约束和变量域。

## 常见风险

1. 同一符号在不同章节含义不同。
2. 参数来自代码但正文未说明。
3. 公式使用未审计数据字段。
4. 归一化、标准化和权重公式未说明指标方向。
5. 非凸优化公式被写成可保证全局最优。

## 输出建议

论文应提供符号说明表，至少包含符号、含义、单位、来源或取值范围。
