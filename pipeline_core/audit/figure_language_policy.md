# 图表中文化审计规则

状态：`PASS_WITH_LIMITATION / SHOWCASE_QUALITY_GATE_UPGRADED`

## 1. 基本要求

1. 图表标题必须中文。
2. 坐标轴必须中文，并在必要时标注单位。
3. 图例必须中文。
4. 图注应说明数据来源、模型边界或估计口径。

## 2. 允许英文术语

允许保留并解释以下术语：

1. `AUC`：分类模型评价指标。
2. `CSV`：表格数据文件格式。
3. `JSON`：结构化数据文件格式。
4. `baseline`：阶段性基准模型或基准方案。
5. `DRAFT_ONLY`：草稿标记。
6. `NOT_FOR_FINAL_SUBMISSION`：不用于最终提交。

## 3. 风险项

1. 图表标题默认英文：`MEDIUM_RISK`。
2. 坐标轴默认英文：`MEDIUM_RISK`。
3. 图例默认英文：`MEDIUM_RISK`。
4. 图表暗示预测值就是真实值：`HIGH_RISK`。
5. 图表暗示已进入提交状态：`HIGH_RISK`。

## 4. 不篡改原则

图表中文化只改变呈现语言，不改变数据、模型输出或统计结论。
