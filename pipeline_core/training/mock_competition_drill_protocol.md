# 模拟赛演练流程

状态：`PASS_WITH_LIMITATION / SUMMER_TRAINING_SELECTION_WORKFLOW_READY`

## 1. 标准流程

1. 新赛题接入。
2. 将材料放入 `cases/active_competition/current_case/data/raw/`。
3. intake 审计。
4. 数据标准化。
5. 约束完整性检查。
6. 题型路由。
7. 模型路线选择。
8. 最小闭环。
9. 验证与敏感性。
10. 论文草稿。
11. 论文质量层检查。
12. 展示或正式披露模式分流。
13. 人工 gate。
14. 禁止自动 `final_submit/`。

## 2. 模拟赛原则

1. 不要求一开始完整做完全部问题。
2. 先做最小闭环，确认数据、模型、代码和结果链路可跑通。
3. 再做扩展模型或高级方案。
4. 不可把 baseline 写成最终结论。
5. 不可把预测结果写成真实结果。
6. 不可跳过人工复核。

## 3. 产出要求

1. intake 审计报告。
2. 数据字典和缺失值报告。
3. 题型路由报告。
4. 模型路线报告。
5. 最小模型输出。
6. 验证与敏感性报告。
7. 草稿或展示材料。
8. 人工复核记录。
