## 1. Tan2005MathModel

文献类型：数学建模教材
引用等级：A_textbook
核心价值：数学建模流程、案例驱动建模、物理机理建模、微分方程模型、网络流模型、风险决策、对策模型、人口与传染病模型、交通流模型、工程仿真模型。
适合支撑：

* 建模流程
* 模型假设
* 模型分类
* 物理/工程/生态/交通/医学类建模思路
* 模型评价与误差分析

限制：

* 不能直接支撑具体赛题数据结论。
* 具体公式需要结合赛题重新推导。
* 正式论文中建议配合专题论文或行业资料。

适合支撑：

* 竞赛建模路线生成
* 算法选择
* MATLAB/Lingo 求解
* 算法擂台
* 预测模型
* 综合评价模型
* 现代优化算法
* 图像处理题

4. 算法结果必须经过 output-contract-validator 和 evidence-trace-checker 验证。
5. 启发式算法不得直接宣称全局最优，除非有严格证明或求解器证书。

## 6. Nocedal2006NumericalOptimization

引用等级：A_advanced_optimization_textbook  
核心价值：线搜索、信赖域、共轭梯度、拟牛顿、L-BFGS、大规模优化、导数计算、无导数优化、最小二乘、非线性方程、约束优化、SQP、罚函数、增广拉格朗日、内点法。  
适合支撑：非线性优化求解、局部搜索、收敛性与停止准则、大规模优化、数值稳定性、无导数黑箱优化、最小二乘拟合、约束优化理论。  
限制：该书支撑数值优化求解理论，不支撑具体赛题背景；不能把局部最优直接写成全局最优。

限制：若赛题模型不是凸问题，不能强行宣称凸优化；使用该教材时必须说明哪些目标和约束满足凸性。
