# 知识卡：决策树模型

来源文献：
- Zhou2016MachineLearning

知识类别：
分类 / 回归 / 可解释模型

适用题型：
规则分类、风险判别、指标分裂、可解释预测

引用等级：
A_machine_learning_textbook

核心思想：
决策树通过特征划分逐步构造树结构，形成可解释的分类或回归规则。

适用场景：
- 特征含义清楚。
- 需要可解释规则。
- 数据规模中小。
- 分类边界可能非线性。
- 作为基准或解释性模型。

生产线调用：
- model-route-generator
- optimizer-arena
- model-critic

风险：
单棵树容易过拟合，需要剪枝、交叉验证或集成方法对照。

需要人工查书补充：
公式细节需查原书对应章节。
