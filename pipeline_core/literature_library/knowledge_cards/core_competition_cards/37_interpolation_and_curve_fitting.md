# 知识卡：插值与曲线拟合

来源文献：

* Xia2016MathModelMATLAB
* Zhang2024ProbabilityStatistics
* Si2015ModelingAlgorithmsApplications

知识类别：数据处理 / 数值方法
适用题型：缺失数据补全、连续曲线构造、实验数据拟合、时间序列平滑
引用等级：A_textbook

核心思想：
插值用于在已知数据点之间估计未知值，拟合用于从数据中估计整体趋势。二者都常用于数据预处理和模型输入构造。

常见方法：

* 线性插值。
* 多项式插值。
* 样条插值。
* 最小二乘拟合。
* 非线性拟合。
* 分段拟合。

适用场景：

* 数据缺少连续表达。
* 需要生成平滑曲线。
* 需要估计中间值。
* 需要构造模型输入。

风险：
插值不能用于远距离外推。高阶多项式可能振荡。
