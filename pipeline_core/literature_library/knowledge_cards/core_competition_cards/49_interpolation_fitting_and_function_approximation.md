# 知识卡：插值、拟合与函数逼近

来源文献：

* Si2015ModelingAlgorithmsApplications
* Xia2016MathModelMATLAB
* Zhang2024ProbabilityStatistics

知识类别：数据处理 / 数值逼近
适用题型：缺失数据补全、曲线重构、实验数据拟合、趋势估计
引用等级：A_competition_algorithm_textbook

核心思想：
插值用于已知点之间的函数估计，拟合用于从有噪声数据中估计整体趋势，函数逼近用于构造可计算的近似模型。

常见方法：

* 线性插值。
* 样条插值。
* 多项式拟合。
* 最小二乘拟合。
* 非线性拟合。
* 函数逼近。

适用场景：

* 观测点离散。
* 数据缺失。
* 模型需要连续函数输入。
* 需要平滑曲线。
* 需要估计参数关系。

风险：
插值不能用于远距离外推。拟合需防止过拟合。
