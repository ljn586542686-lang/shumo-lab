# 知识卡：网络流模型

来源文献：

* Tan2005MathModel
* Pu2024OperationsResearch
* Si2015ModelingAlgorithmsApplications

知识类别：图论优化
适用题型：物流、交通、供应链、管网、生产计划、任务分派
引用等级：A_textbook

核心思想：
将系统抽象为节点和边，边上设置容量、费用和流量，通过最大流、最小费用流或多源多汇网络模型描述资源传输。

核心元素：

* 节点
* 边
* 容量
* 费用
* 源点
* 汇点
* 流量守恒

常见目标：

* 最大通过量。
* 最小运输费用。
* 满足需求的最低成本。
* 最大覆盖或最短路径。

适用场景：

* 存在天然网络结构。
* 数据包含节点、线路、容量、距离或成本。
* 结果需要可视化路径。

风险：
如果路径选择还涉及车辆容量、时间窗和访问顺序，应扩展为车辆路径或组合优化。
