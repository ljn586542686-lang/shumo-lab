# 知识卡：偏最小二乘回归 PLS

来源文献：
- Zhou2016MachineLearning

* Si2015ModelingAlgorithmsApplications
* Zhang2024ProbabilityStatistics

知识类别：回归分析 / 多重共线性处理
适用题型：多指标预测、小样本多变量回归、变量强相关建模
引用等级：B_competition_algorithm_textbook

核心思想：
偏最小二乘回归适合自变量较多且存在多重共线性的情况，通过提取潜变量建立自变量和因变量之间的稳定关系。

适用场景：

* 自变量多。
* 样本量较小。
* 变量之间强相关。
* 普通最小二乘不稳定。
* 需要预测解释兼顾。

常见输出：

* 潜变量。
* 回归系数。
* 解释方差。
* 预测误差。
* 变量贡献。

风险：
潜变量解释性弱，需要结合实际背景解释。
