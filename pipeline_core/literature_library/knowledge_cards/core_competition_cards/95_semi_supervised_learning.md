# 知识卡：半监督学习

来源文献：
- Zhou2016MachineLearning

知识类别：
机器学习高级方法

适用题型：
少量标注数据、大量未标注数据、分类预测

引用等级：
B_machine_learning_textbook

核心思想：
半监督学习利用少量有标签样本和大量无标签样本共同训练模型，适合标注成本高的数据场景。

适用场景：
- 标签数据少。
- 未标注数据多。
- 分类结构明显。
- 标签获取成本高。

生产线调用：
- model-route-generator
- model-critic

风险：
数模竞赛中若没有明确的未标注数据结构，不建议强行使用。应作为可选增强模型。

需要人工查书补充：
公式细节需查原书对应章节。
