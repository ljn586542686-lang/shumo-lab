# 知识卡：概率图模型

来源文献：
- Zhou2016MachineLearning

知识类别：
概率建模 / 结构化学习

适用题型：
变量依赖关系、序列数据、因果近似、联合概率建模

引用等级：
B_machine_learning_textbook

核心思想：
概率图模型用图结构表示随机变量之间的依赖关系，可用于建模复杂联合分布、推断隐变量或处理结构化数据。

适用场景：
- 变量关系复杂。
- 存在隐状态。
- 序列或结构化数据。
- 需要概率推断。

生产线调用：
- problem-type-router
- model-route-generator
- model-critic

风险：
模型结构学习和参数估计复杂。正式比赛中除非题目高度匹配，否则不宜作为主模型。
