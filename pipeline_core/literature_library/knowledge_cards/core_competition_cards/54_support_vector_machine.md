# 知识卡：支持向量机 SVM

来源文献：
- Zhou2016MachineLearning
- Boyd2004ConvexOptimization

* Si2015ModelingAlgorithmsApplications

知识类别：机器学习 / 分类回归
适用题型：分类预测、小样本非线性识别、故障诊断、质量判别
引用等级：B_competition_algorithm_textbook

核心思想：
支持向量机通过最大化分类间隔构造分类超平面，并可借助核函数处理非线性分类或回归问题。

适用场景：

* 样本量中小。
* 维度较高。
* 分类边界非线性。
* 需要对照机器学习模型。
* 故障诊断或模式识别。

常见输出：

* 分类准确率。
* 混淆矩阵。
* 召回率。
* 精确率。
* 预测误差。

风险：
参数和核函数选择对结果影响大。必须与基准模型对照，并避免黑箱化表达。
