# 知识卡：随机变量与概率分布

来源文献：

* Zhang2024ProbabilityStatistics

知识类别：概率模型
适用题型：随机需求、随机误差、服务时间、寿命分布、抽样数据
引用等级：A_textbook

核心思想：
用随机变量描述随机现象的数值结果，用分布函数或概率密度刻画其取值规律。

常见分布：

* 二项分布。
* 泊松分布。
* 均匀分布。
* 正态分布。
* 指数分布。
* 其他连续或离散分布。

适用场景：

* 计数型随机事件。
* 到达次数。
* 测量误差。
* 产品寿命。
* 服务时间。
* 样本波动。

论文要求：
必须说明为何选择该分布，可通过数据拟合、经验背景或题面假设支撑。

风险：
不能只因为正态分布常见就默认正态。需要分布检验或合理解释。
