# 知识卡：线性规划

来源文献：
- Boyd2004ConvexOptimization

* Pu2024OperationsResearch
* Tan2005MathModel
* Si2015ModelingAlgorithmsApplications

知识类别：优化模型
适用题型：资源分配、生产计划、运输、成本最小化、收益最大化
引用等级：A_textbook

核心思想：
当目标函数和约束条件均可表示为决策变量的线性函数时，使用线性规划。它是数模竞赛中最稳定、最容易解释的基准优化模型。

标准形式：
max/min c^T x
s.t. A x <= b
x >= 0

常见变量：

* 产量
* 分配量
* 投资比例
* 运输量
* 时间分配
* 资源使用量

适用场景：

* 目标和约束具有线性关系。
* 结果需要强解释性。
* 需要基准模型。
* 数据规模中等。

求解方法：

* 单纯形法
* 内点法
* MATLAB linprog
* Python scipy.optimize.linprog

论文表达：
“在目标函数和约束近似线性的前提下，建立线性规划模型，并以该模型作为基准方案。”

风险：
如果真实关系明显非线性，线性规划只能作为近似模型或基准模型。
