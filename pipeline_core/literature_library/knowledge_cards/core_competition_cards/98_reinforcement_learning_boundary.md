# 知识卡：强化学习使用边界

来源文献：
- Zhou2016MachineLearning

知识类别：
序贯决策 / 高级机器学习

适用题型：
动态策略、智能体决策、试错学习、控制问题

引用等级：
B_machine_learning_textbook

核心思想：
强化学习通过智能体与环境交互学习策略，适合序贯决策问题。但在数模竞赛中，若没有足够仿真环境和训练时间，不宜轻易作为主模型。

适用场景：
- 多阶段决策。
- 状态转移明确。
- 有可模拟环境。
- 策略收益可定义。

生产线调用：
- problem-type-router
- model-route-generator
- model-critic

风险：
训练成本高、可解释性弱、稳定性差。国赛中通常只适合作为思路补充，不建议作为核心模型，除非队伍有充分实现能力。

需要人工查书补充：
公式细节需查原书对应章节。
