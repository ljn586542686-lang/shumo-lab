# 知识卡：几何凸优化与距离问题

来源文献：
- Boyd2004ConvexOptimization

知识类别：
几何优化 / 距离模型

适用题型：
投影、点到集合距离、集合间距离、定位、覆盖、几何约束

引用等级：
A_convex_optimization_textbook

核心思想：
许多几何问题可以转化为凸优化问题，例如投影到集合、集合间距离、欧氏距离与角度、几何定位、最大内接或最小外接几何体等。

适用场景：
- 几何遮蔽。
- 最近点计算。
- 距离约束。
- 定位和布点。
- 空间规划。
- 目标覆盖。

生产线调用：
- problem-type-router
- model-route-generator
- optimizer-arena
- theory-checker

风险：
若几何对象非凸或存在离散选择，则问题可能转化为非凸或组合优化，需要另行处理。

公式细节需查原书对应章节。
