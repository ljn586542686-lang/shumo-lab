# 知识卡：线性规划对偶理论

来源文献：

* Pu2024OperationsResearch

知识类别：优化理论
适用题型：资源价值解释、影子价格、约束经济意义
引用等级：A_textbook

核心思想：
每个线性规划问题都有对应的对偶问题。原问题通常描述资源分配，对偶问题可解释资源的边际价值或约束的经济含义。

适用场景：

* 需要解释资源约束的价值。
* 需要判断哪类资源最紧缺。
* 需要给出管理建议。
* 需要增强论文理论层次。

常见输出：

* 对偶变量
* 影子价格
* 紧约束识别
* 资源边际收益

论文表达：
“通过对偶变量解释资源约束的边际价值，识别影响最优方案的关键资源。”

风险：
对偶解释依赖线性规划假设。如果原模型是启发式或非线性模型，不能强行套用对偶理论。
