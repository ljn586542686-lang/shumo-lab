# 知识卡：方差分析与假设检验

来源文献：

* Si2015ModelingAlgorithmsApplications
* Zhang2024ProbabilityStatistics

知识类别：数理统计 / 统计检验
适用题型：多组比较、因素影响分析、实验结果显著性检验
引用等级：A_competition_algorithm_textbook

核心思想：
假设检验用于判断样本差异是否具有统计意义，方差分析用于比较多个因素或水平对结果的影响。

适用场景：

* 多方案比较。
* 多因素实验。
* 模型结果显著性分析。
* 参数影响识别。
* 算法效果比较。

常见输出：

* 显著性水平。
* p 值。
* 方差分解。
* 组间差异。
* 因素贡献度。

风险：
必须说明独立性、正态性和方差齐性等假设。样本过小慎用。
