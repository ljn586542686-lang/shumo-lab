# 知识卡：降维与度量学习

来源文献：
- Zhou2016MachineLearning

知识类别：
特征工程 / 无监督学习

适用题型：
高维指标、可视化、特征压缩、综合评价前处理

引用等级：
A_machine_learning_textbook

核心思想：
降维将高维数据映射到低维表示，减少冗余、噪声和计算负担；度量学习用于学习适合任务的距离度量。

适用场景：
- 特征维度高。
- 变量相关性强。
- 需要可视化。
- 需要减少过拟合。
- 需要构造低维评价指标。

生产线调用：
- data-auditor
- model-route-generator
- model-critic

风险：
降维后变量解释性可能下降。必须解释主成分或低维特征含义。

需要人工查书补充：
公式细节需查原书对应章节。
