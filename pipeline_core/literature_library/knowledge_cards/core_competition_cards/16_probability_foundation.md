# 知识卡：概率基础与随机事件

来源文献：

* Zhang2024ProbabilityStatistics

知识类别：概率论基础
适用题型：随机事件、不确定性、风险计算、概率评估
引用等级：A_textbook

核心思想：
将不确定现象抽象为随机事件，用概率刻画事件发生可能性，用条件概率、独立性和全概率等工具分析复杂随机关系。

常见概念：

* 样本空间。
* 随机事件。
* 概率。
* 条件概率。
* 独立性。
* 全概率公式。
* 贝叶斯公式。

适用场景：

* 事件发生概率估计。
* 风险建模。
* 故障概率。
* 分类判断。
* 不确定性传播。

风险：
概率值必须有数据、假设或文献依据，不能随意设定。
