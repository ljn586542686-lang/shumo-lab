# 知识卡：物理机理建模

来源文献：

* Tan2005MathModel
* Xia2016MathModelMATLAB

知识类别：机理模型
适用题型：运动、热传导、流体、力学、电磁、工程过程
引用等级：A_textbook

核心思想：
从物理定律、守恒关系、边界条件和初始条件出发建立模型。机理模型强调变量有物理意义，参数可解释。

常见步骤：

1. 确定系统边界。
2. 明确状态变量。
3. 写出守恒关系或动力学方程。
4. 设置边界和初始条件。
5. 数值求解。
6. 检验物理合理性。

适用场景：

* 题目具有明确物理机制。
* 需要高可解释性。
* 数据不足但机制明确。

风险：
推导错误会严重影响论文。必须进行单位检查和数量级检查。
