# 知识卡：关键路径法与计划评审技术

来源文献：

* Si2015ModelingAlgorithmsApplications
* Pu2024OperationsResearch

知识类别：项目管理 / 网络计划
适用题型：工程进度、任务调度、项目压缩、工期优化
引用等级：A_competition_algorithm_textbook

核心思想：
将项目分解为活动和依赖关系，构建有向网络，通过计算最早开始、最迟开始、总时差和关键路径分析项目总工期。

常见变量：

* 活动持续时间。
* 前置约束。
* 最早开始时间。
* 最迟开始时间。
* 总时差。
* 关键路径。
* 项目总工期。

适用场景：

* 工程施工计划。
* 生产流程调度。
* 项目工期优化。
* 任务依赖网络。

风险：
若活动时间具有随机性，应加入 PERT 三点估计或蒙特卡洛仿真。
