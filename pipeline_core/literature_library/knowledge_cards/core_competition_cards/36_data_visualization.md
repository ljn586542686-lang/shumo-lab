# 知识卡：数据可视化与图表表达

来源文献：

* Xia2016MathModelMATLAB
* Zhang2024ProbabilityStatistics
* Si2015ModelingAlgorithmsApplications

知识类别：论文表达 / 结果展示
适用题型：所有含数据、轨迹、拟合、误差、敏感性结果的题目
引用等级：A_tool_textbook

核心思想：
图表用于展示数据结构、模型结果、误差、趋势和对比。高质量图表能显著提升论文可读性和可信度。

常见图表：

* 折线图。
* 散点图。
* 柱状图。
* 热力图。
* 轨迹图。
* 收敛曲线。
* 残差图。
* 敏感性曲线。
* 箱线图。
* 相关矩阵。

图表要求：

1. 图名明确。
2. 坐标轴有单位。
3. 图例清晰。
4. 不堆叠无关图。
5. 图表必须能在 evidence_map 中追溯来源。

风险：
图表不能替代模型解释。每张图必须服务于论文结论。
