# 知识卡：人口预测与控制模型

来源文献：

* Tan2005MathModel
* Zhang2024ProbabilityStatistics

知识类别：动态预测模型
适用题型：人口预测、老龄化、教育医疗需求、资源规划
引用等级：A_textbook

核心思想：
用增长方程、阻滞增长、年龄结构或随机模型描述人口随时间变化，并根据政策或资源约束进行预测和控制。

常见模型：

* Malthus 指数增长。
* Logistic 阻滞增长。
* 年龄结构模型。
* 随机人口模型。
* 控制模型。

常见变量：

* 总人口。
* 出生率。
* 死亡率。
* 迁移率。
* 年龄结构。
* 生育政策参数。

风险：
人口模型对政策、迁移和外部环境敏感。必须做情景分析。

## 公式细节边界

公式细节需查原书对应章节。知识卡仅作为方法选择和风险审查依据。不得直接替代论文中的模型推导。
