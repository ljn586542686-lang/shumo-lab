# 知识卡：贪心算法与启发式搜索

来源文献：

* Tan2005MathModel
* Pu2024OperationsResearch
* Si2015ModelingAlgorithmsApplications

知识类别：近似优化算法
适用题型：大规模组合优化、高维搜索、快速可行解
引用等级：B_textbook

核心思想：
在难以精确求解的情况下，通过局部收益、优先规则、候选筛选、局部调整等策略快速得到较优可行解。

常见流程：

1. 构造候选集合。
2. 定义收益或代价指标。
3. 按指标排序。
4. 逐步选择当前最优候选。
5. 检查约束。
6. 局部修正。
7. 输出可行解。

适用场景：

* 时间有限。
* 问题规模大。
* 精确算法计算量过高。
* 需要算法擂台中的对照算法或初始解。

风险：
通常不能证明全局最优。必须配合对照实验、敏感性分析或多随机种子检验。
