# 知识卡：ARIMA 与季节性时间序列

来源文献：

* Si2015ModelingAlgorithmsApplications
* Zhang2024ProbabilityStatistics
* Xia2016MathModelMATLAB

知识类别：时间序列预测
适用题型：需求预测、销量预测、人口预测、周期波动、趋势外推
引用等级：A_competition_algorithm_textbook

核心思想：
ARIMA 通过差分实现平稳化，再用自回归和移动平均项描述序列相关结构。季节性序列还需处理周期性波动。

常见步骤：

1. 绘制时间序列。
2. 平稳性检查。
3. 差分处理。
4. 识别阶数。
5. 参数估计。
6. 残差检验。
7. 预测。
8. 误差评价。

适用场景：

* 历史数据较长。
* 时间间隔固定。
* 存在趋势或周期。
* 需要短中期预测。

风险：
预测外推期过长会降低可靠性。突发政策或环境变化会破坏时间序列结构。
