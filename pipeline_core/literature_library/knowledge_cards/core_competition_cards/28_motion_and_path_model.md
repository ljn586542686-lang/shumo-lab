# 知识卡：通勤路线与步行用时

第 28 号卡用步行通勤作例子，说明怎样核对路程、时间和速度的单位。这个例子是后来为教学补写的。

来源文献：本项目公开教学说明。知识类别：基础数量关系。适用题型：路线用时估计。
引用等级：教学说明。正式引用须另行核对来源。

## 核心思想与适用场景

估算从家步行到车站的时间时，将路段用时和路口等待分开记录。假设一段平路长 600 m，步速为 1.2 m/s，则步行用时为 500 s；等待时间需要单独观测。该数值仅用于展示单位换算。

## 生产线调用

题意分析时确认距离、用时和单位；选型时说明平均步速的依据；复核时用另一次观测检查预测误差。

## 风险

坡度、拥挤和停顿会改变步速。在同一段路上估计又检验步速，会低估预测误差。
