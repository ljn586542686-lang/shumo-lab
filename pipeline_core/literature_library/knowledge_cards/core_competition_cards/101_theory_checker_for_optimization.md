# 知识卡：优化模型理论审查清单

来源文献：
- Boyd2004ConvexOptimization
- Nocedal2006NumericalOptimization

知识类别：
模型审查 / theory-checker

适用题型：
所有优化类题目

引用等级：
pipeline_rule

核心思想：
优化模型进入论文前，应检查模型类型、凸性、可行性、约束完整性、求解算法匹配性和最优性表述。

适用场景：
- 所有优化类模型。
- 非线性规划。
- 多目标优化。
- 整数规划。
- 启发式优化。
- 凸优化。

生产线调用：
- theory-checker
- model-critic
- optimizer-arena
- case-freezer

审查清单：
- 决策变量是否完整。
- 目标函数是否贴合题意。
- 约束是否遗漏。
- 单位是否一致。
- 可行域是否非空。
- 问题是否凸。
- 若非凸，是否有多起点或算法对照。
- 求解器是否匹配模型。
- 是否检查约束违反。
- 是否避免把局部最优写成全局最优。

风险：
未通过 theory-checker 的优化结果不得直接进入最终论文。

需要人工查书补充：
无。该卡为生产线规则卡。
