# 知识卡：聚类分析

来源文献：
- Zhou2016MachineLearning
- Si2015ModelingAlgorithmsApplications

知识类别：
无监督学习

适用题型：
分群、模式发现、区域分类、客户/对象分组

引用等级：
A_machine_learning_textbook

核心思想：
聚类在无标签数据中寻找相似对象群组，可用于发现数据结构、分层建模或评价对象分类。

适用场景：
- 没有标签。
- 需要对象分组。
- 指标较多。
- 后续要分组建模。
- 需要数据结构探索。

生产线调用：
- data-auditor
- model-route-generator
- model-critic

风险：
聚类结果受距离度量、标准化和聚类数影响，需要稳定性检查。

需要人工查书补充：
公式细节需查原书对应章节。
