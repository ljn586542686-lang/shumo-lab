# 知识卡：动态规划

来源文献：

* Pu2024OperationsResearch
* Tan2005MathModel
* Si2015ModelingAlgorithmsApplications

知识类别：多阶段决策
适用题型：路径规划、库存、资源分配、生产计划、最优控制
引用等级：A_textbook

核心思想：
将复杂决策问题分解为多个阶段，每一阶段根据当前状态做出决策，并通过状态转移递推求得整体最优。

核心要素：

1. 阶段。
2. 状态。
3. 决策。
4. 状态转移。
5. 阶段收益或成本。
6. 递推方程。
7. 边界条件。

适用场景：

* 多阶段决策。
* 当前选择影响未来状态。
* 问题具有最优子结构。
* 状态空间可控。

常见论文表达：
“将原问题按时间或过程阶段分解，建立状态转移方程，并利用动态规划递推求解。”

风险：
状态维度过高会导致维数灾难。需要状态压缩或启发式近似。
