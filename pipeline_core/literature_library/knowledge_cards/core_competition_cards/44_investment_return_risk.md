# 知识卡：投资收益—风险优化模型

来源文献：

* Si2015ModelingAlgorithmsApplications
* Pu2024OperationsResearch
* Zhang2024ProbabilityStatistics

知识类别：风险收益权衡 / 多目标优化
适用题型：投资组合、资源配置、风险控制、收益最大化
引用等级：A_competition_algorithm_textbook

核心思想：
投资类问题通常同时追求收益最大和风险最小，可建立多目标规划，并通过固定风险水平、固定收益水平或加权目标函数转化为单目标优化。

常见变量：

* 投资比例或金额 x_i
* 收益率 r_i
* 风险损失率 q_i
* 交易费用 p_i
* 总收益 Q
* 风险水平 a

常见建模方式：

1. 固定风险水平，最大化收益。
2. 固定收益水平，最小化风险。
3. 收益和风险加权综合优化。
4. 加入交易费、投资上限、资金总量约束。

适用场景：

* 投资决策。
* 多项目资金分配。
* 风险预算。
* 多目标资源配置。

风险：
风险度量方式需要解释；权重或风险阈值必须做敏感性分析。
