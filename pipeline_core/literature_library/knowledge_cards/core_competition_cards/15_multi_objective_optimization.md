# 知识卡：多目标优化与权衡分析

来源文献：
- Boyd2004ConvexOptimization

* Tan2005MathModel
* Pu2024OperationsResearch
* Si2015ModelingAlgorithmsApplications

知识类别：多目标决策
适用题型：成本—收益、效率—公平、风险—收益、覆盖—资源消耗
引用等级：B_textbook

核心思想：
当题目同时存在多个相互冲突的目标时，需要将多个目标纳入统一优化框架，形成权衡解。

常见方式：

1. 加权和法。
2. 分层优化。
3. 约束转化。
4. Pareto 分析。
5. 目标归一化。

使用要求：

* 指标量纲必须统一或归一化。
* 权重必须说明来源。
* 权重需要敏感性分析。
* 不要把主观权重包装为客观最优。

论文位置：

* 目标函数设计。
* 方案比较。
* 灵敏度分析。
* 结果解释。

风险：
权重主观性是主要风险，需要 sensitivity-runner 介入。
