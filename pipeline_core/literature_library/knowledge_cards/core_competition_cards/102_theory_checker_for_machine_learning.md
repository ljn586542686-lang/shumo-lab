# 知识卡：机器学习模型审查清单

来源文献：
- Zhou2016MachineLearning

知识类别：
机器学习审查 / model-critic

适用题型：
所有机器学习类题目

引用等级：
pipeline_rule

核心思想：
机器学习模型进入论文前，应检查数据划分、样本量、特征工程、模型选择、参数调优、泛化误差和解释性。

适用场景：
- 分类。
- 回归。
- 聚类。
- 神经网络。
- SVM。
- 集成学习。
- 特征选择。
- 降维。

生产线调用：
- model-critic
- output-contract-validator
- result-interpreter
- case-freezer

审查清单：
- 是否有训练集/测试集划分。
- 是否存在数据泄漏。
- 样本量是否足够。
- 类别是否不平衡。
- 是否设置基准模型。
- 是否报告训练外指标。
- 是否做交叉验证。
- 是否解释特征影响。
- 是否检查过拟合。
- 是否避免黑箱模型主导全文。

风险：
未通过机器学习审查的模型只能作为探索性结果，不宜作为核心结论。

需要人工查书补充：
无。该卡为生产线规则卡。
