# 知识卡：趋势预测与时间序列建模

来源文献：

* Tan2005MathModel
* Zhang2024ProbabilityStatistics
* Xia2016MathModelMATLAB
* Si2015ModelingAlgorithmsApplications

知识类别：预测模型
适用题型：人口预测、需求预测、增长趋势、动态变化
引用等级：B_textbook

核心思想：
根据历史数据随时间变化的规律，建立趋势模型、增长模型或随机过程模型预测未来。

常见模型：

* 线性趋势。
* 指数增长。
* Logistic 增长。
* 分段趋势。
* 移动平均。
* 差分模型。
* 随机模型。

适用场景：

* 时间顺序明确。
* 历史数据较完整。
* 预测期不宜过长。
* 外部冲击较弱或可建情景。

风险：
外推风险高。必须说明预测期、误差和局限性。
