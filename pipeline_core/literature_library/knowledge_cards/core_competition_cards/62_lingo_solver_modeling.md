# 知识卡：Lingo 建模与优化求解

来源文献：

* Si2015ModelingAlgorithmsApplications

知识类别：软件实现 / 优化求解
适用题型：线性规划、整数规划、运输问题、目标规划、组合优化
引用等级：A_tool_textbook

核心思想：
Lingo 适合表达和求解优化模型，尤其适合线性规划、整数规划、运输问题和目标规划。它可以作为 MATLAB 之外的优化求解工具。

适用场景：

* 模型变量和约束清晰。
* 需要快速验证优化结果。
* 需要与 MATLAB 结果交叉验证。
* 需要求解整数规划或线性规划。

生产线用途：

* optimizer-arena 对照求解。
* output-contract-validator 验证结果。
* final_submit 附录代码补充。

风险：
论文中不能只给 Lingo 代码，必须写明数学模型。
