# 知识卡：对策模型与博弈分析

来源文献：

* Tan2005MathModel

知识类别：博弈论 / 多主体决策
适用题型：攻防对抗、竞争策略、资源争夺、定价策略
引用等级：B_textbook

核心思想：
当多个主体的收益相互影响时，用策略集和收益矩阵描述其相互作用，并分析均衡策略。

常见元素：

* 参与者。
* 策略集。
* 收益矩阵。
* 纯策略。
* 混合策略。
* 均衡解。

适用场景：

* 对抗问题。
* 竞争问题。
* 策略选择。
* 安全与防御。

风险：
收益矩阵构造主观性强。若没有充分依据，不宜强行使用博弈模型。
