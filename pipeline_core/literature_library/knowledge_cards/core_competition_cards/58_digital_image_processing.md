# 知识卡：数字图像处理

来源文献：

* Si2015ModelingAlgorithmsApplications
* Xia2016MathModelMATLAB

知识类别：图像处理 / 数字信号
适用题型：图像识别、图像增强、水印、防伪、加密、隐藏、空间滤波
引用等级：B_competition_algorithm_textbook

核心思想：
图像处理将图像看作矩阵或二维信号，通过空间域和频域方法进行增强、滤波、特征提取、加密、隐藏或水印处理。

常见方法：

* 灰度变换。
* 空间滤波。
* 频域变换。
* 图像水印。
* 图像加密。
* 图像隐藏。
* 边缘或纹理特征提取。

适用场景：

* 图像类赛题。
* 遥感或医学图像。
* 安全水印。
* 图像质量评价。
* 目标识别前处理。

风险：
图像处理结果必须有客观评价指标，不要只凭视觉效果判断。
