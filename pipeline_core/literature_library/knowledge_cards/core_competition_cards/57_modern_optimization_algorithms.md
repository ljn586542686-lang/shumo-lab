# 知识卡：现代优化算法

来源文献：
- Nocedal2006NumericalOptimization（仅支撑数值优化边界，不支撑遗传算法本身）

* Si2015ModelingAlgorithmsApplications

知识类别：启发式优化 / 智能优化
适用题型：复杂优化、非凸优化、组合优化、多峰函数、高维搜索
引用等级：B_competition_algorithm_textbook

核心思想：
现代优化算法通过模拟自然过程、遗传进化或随机搜索机制，在复杂可行域中寻找较优解。

常见算法：

1. 模拟退火算法。
2. 遗传算法。
3. 改进遗传算法。
4. 粒子群、蚁群等可作为扩展方法。

适用场景：

* 目标函数不可导。
* 约束复杂。
* 可行域非凸。
* 精确算法困难。
* 需要算法擂台增强竞争力。

生产线要求：

1. 设置随机种子。
2. 记录参数。
3. 与基准算法比较。
4. 做多次重复实验。
5. 不宣称全局最优。

风险：
启发式算法容易被质疑“调参凑结果”，必须做收敛曲线、对照算法和敏感性分析。
