# 知识卡：运输问题

来源文献：

* Pu2024OperationsResearch

知识类别：运筹优化 / 网络分配
适用题型：物流运输、供应分配、仓库到需求点配送
引用等级：A_textbook

核心思想：
运输问题是在多个供应点和多个需求点之间分配运输量，使总运输成本最低或总收益最高。

典型变量：
x_ij：从供应点 i 到需求点 j 的运输量。

常见约束：

1. 每个供应点发出量不超过供应量。
2. 每个需求点接收量满足需求。
3. 运输量非负。
4. 可加入容量、时间、路径限制。

适用场景：

* 供应链配送。
* 物资调运。
* 物流成本优化。
* 产销不平衡问题。

求解方法：

* 表上作业法。
* 线性规划。
* 最小费用流。
* MATLAB/Python 优化求解。

风险：
若存在车辆路径、时间窗、多级仓储，普通运输问题需要扩展为路径规划或网络流模型。
