# 知识卡：参数估计

来源文献：

* Zhang2024ProbabilityStatistics
* Tan2005MathModel

知识类别：数理统计 / 参数辨识
适用题型：模型校准、数据拟合、未知参数估计
引用等级：A_textbook

核心思想：
根据样本数据估计总体参数或模型参数，使模型输出更接近实际观测。

常见方法：

* 矩估计。
* 最大似然估计。
* 最小二乘估计。
* 区间估计。
* 参数辨识。

常见输出：

* 参数估计值。
* 标准误。
* 置信区间。
* 拟合误差。
* 残差分析。

适用论文位置：

* 参数求解。
* 数据拟合。
* 模型校准。
* 误差分析。

风险：
如果参数不可辨识或样本量太小，估计结果不稳定。必须做敏感性分析。
