# 知识卡：生态与种群动力学模型

来源文献：

* Tan2005MathModel

知识类别：微分方程 / 生态系统
适用题型：生态竞争、种群增长、捕食关系、植物生长
引用等级：A_textbook

核心思想：
通过微分方程描述生物种群随时间变化，参数刻画增长率、环境容量、竞争系数和捕食关系。

常见模型：

* 指数增长。
* Logistic 增长。
* 二物种竞争。
* 捕食者—被捕食者。
* 植物生长模型。

适用论文位置：

* 动态系统建模。
* 参数辨识。
* 稳定性分析。
* 生态预测。

风险：
生态参数难确定，必须说明数据来源或估计方法。
