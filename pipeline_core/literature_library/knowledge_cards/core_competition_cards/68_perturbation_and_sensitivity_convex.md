# 知识卡：扰动分析与凸优化敏感性

来源文献：
- Boyd2004ConvexOptimization

知识类别：
敏感性分析 / 对偶解释

适用题型：
资源约束变化、参数扰动、右端项变化、鲁棒性分析

引用等级：
A_convex_optimization_textbook

核心思想：
优化问题的最优值会随参数变化而变化。通过扰动分析和对偶变量，可以解释约束变化对最优值的影响。

适用场景：
- 资源上限变化。
- 需求变化。
- 成本系数变化。
- 风险阈值变化。
- 右端项扰动。

生产线调用：
- sensitivity-runner
- result-interpreter
- model-critic
- theory-checker

风险：
只适用于模型结构明确且扰动范围合理的情况。不能把局部敏感性结论外推到大范围变化。
