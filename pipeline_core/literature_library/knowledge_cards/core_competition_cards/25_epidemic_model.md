# 知识卡：传染病与传播模型

来源文献：

* Tan2005MathModel
* Zhang2024ProbabilityStatistics

知识类别：微分方程 / 随机传播
适用题型：疫情传播、舆情扩散、信息传播、病毒传播
引用等级：A_textbook

核心思想：
将总体划分为易感者、感染者、恢复者或移除者，通过群体间转移关系建立动态方程。

常见模型：

* SI。
* SIS。
* SIR。
* 带出生死亡的 SIR。
* 改进传播模型。

常见变量：

* S(t)：易感者。
* I(t)：感染者。
* R(t)：恢复或移除者。
* beta：传播率。
* gamma：恢复率。

适用场景：

* 传播机制明确。
* 需要预测峰值、规模或防控效果。
* 可估计传播参数。

风险：
参数敏感性强。必须做参数辨识和扰动分析。
