# 知识卡：存储论与库存模型

来源文献：

* Pu2024OperationsResearch
* Tan2005MathModel

知识类别：库存管理 / 成本优化
适用题型：订货、补货、仓储、生产计划、供应链
引用等级：A_textbook

核心思想：
库存模型在订货成本、持有成本、缺货成本和需求之间寻找平衡，确定最优订货量或补货策略。

常见变量：

* 订货量 Q
* 需求率 D
* 订货成本
* 持有成本
* 缺货成本
* 补货周期

常见模型：

* 确定性库存模型。
* 随机性库存模型。
* 经济订货批量模型。
* 多周期库存模型。

适用论文位置：

* 供应链模型
* 库存优化
* 成本分析
* 策略建议

风险：
需求不确定时不能只用确定性模型，需加入随机需求或敏感性分析。

## 公式细节边界

公式细节需查原书对应章节。知识卡仅作为方法选择和风险审查依据。不得直接替代论文中的模型推导。
