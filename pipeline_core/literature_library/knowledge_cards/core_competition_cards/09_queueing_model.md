# 知识卡：排队论模型

来源文献：

* Pu2024OperationsResearch
* Tan2005MathModel

知识类别：随机服务系统
适用题型：窗口服务、交通排队、医院排队、物流装卸、网络服务
引用等级：A_textbook

核心思想：
排队论描述顾客到达、等待、接受服务和离开系统的过程，用到达率、服务率、队长、等待时间等指标评价服务系统性能。

常见变量：

* 到达率 lambda
* 服务率 mu
* 服务台数量 c
* 平均队长 L
* 平均等待时间 W
* 系统利用率 rho

适用场景：

* 到达过程具有随机性。
* 服务能力有限。
* 需要优化服务台数量或等待时间。
* 交通、物流、医疗、通信等系统。

常见输出：

* 平均等待时间。
* 平均排队长度。
* 系统利用率。
* 服务台配置建议。

风险：
排队模型对到达分布和服务时间分布敏感。必须说明分布假设。
