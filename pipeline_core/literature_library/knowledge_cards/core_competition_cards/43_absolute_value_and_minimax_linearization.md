# 知识卡：绝对值、最大值与极小极大问题线性化

来源文献：

* Si2015ModelingAlgorithmsApplications
* Pu2024OperationsResearch

知识类别：线性规划转化 / 模型等价变换
适用题型：误差最小化、极差控制、鲁棒拟合、最大偏差最小化
引用等级：A_competition_algorithm_textbook

核心思想：
很多看似非线性的绝对值、最大值、极小极大问题，可以通过引入辅助变量转化为线性规划，从而提高求解稳定性和可解释性。

典型转化：

1. |x| 可通过正负变量拆分转化。
2. min max_i e_i 可通过引入辅助变量 v，并增加 e_i <= v 的约束转化。
3. L1 误差最小化可转化为线性规划。
4. Chebyshev 极小极大拟合可转化为线性规划。

适用场景：

* 最小最大误差。
* 总绝对偏差最小化。
* 鲁棒线性拟合。
* 公平性或最坏情况控制。

适合论文位置：

* 模型转化
* 目标函数设计
* 求解算法说明
* 鲁棒性分析

风险：
转化后的变量含义必须解释清楚，否则论文可读性下降。
