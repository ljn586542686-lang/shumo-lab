# 知识卡：机器学习中的凸优化模型

来源文献：
- Boyd2004ConvexOptimization
- Zhou2016MachineLearning

知识类别：
机器学习优化 / 理论支撑

适用题型：
SVM、逻辑回归、正则化回归、稀疏学习

引用等级：
A_cross_textbook

核心思想：
部分机器学习模型可表示为凸优化问题，如正则化线性回归、逻辑回归、支持向量机等。识别凸结构有助于解释模型训练的稳定性和全局最优性。

适用场景：
- 线性分类。
- 正则化回归。
- SVM。
- 稀疏特征选择。
- 逻辑回归。

生产线调用：
- model-route-generator
- theory-checker
- model-critic

风险：
神经网络一般不是凸优化问题，不能套用凸优化全局最优结论。
