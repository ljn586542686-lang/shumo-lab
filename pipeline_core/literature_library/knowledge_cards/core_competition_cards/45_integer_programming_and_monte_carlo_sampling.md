# 知识卡：整数规划与蒙特卡洛随机取样

来源文献：

* Si2015ModelingAlgorithmsApplications
* Pu2024OperationsResearch
* Zhang2024ProbabilityStatistics

知识类别：整数规划 / 随机搜索
适用题型：0-1 选择、任务分配、组合优化、装载、排班
引用等级：A_competition_algorithm_textbook

核心思想：
整数规划适合处理离散决策，蒙特卡洛随机取样可以作为大规模组合问题的候选解生成或对照搜索方法。

适用场景：

* 精确求解困难。
* 变量为整数或 0-1。
* 可行域巨大。
* 需要快速找到可行解。
* 需要算法擂台中的随机基准。

常见流程：

1. 定义整数变量。
2. 生成随机候选解。
3. 检查约束可行性。
4. 计算目标函数。
5. 保留优良解。
6. 多随机种子重复试验。
7. 输出最好解和稳定性统计。

风险：
蒙特卡洛方法不能保证全局最优。必须记录随机种子、迭代次数和结果稳定性。
