# 知识卡：反问题与参数辨识

来源文献：

* Tan2005MathModel
* Zhang2024ProbabilityStatistics
* Xia2016MathModelMATLAB

知识类别：参数估计 / 反演模型
适用题型：图像重建、测量反演、医学检测、物理探测、模型校准
引用等级：A_textbook

核心思想：
根据观测结果反推未知参数、输入或空间分布，使模型输出尽可能接近观测数据。

常见形式：
min sum_i (y_i - f(x_i, theta))^2

常见方法：

* 最小二乘。
* 迭代法。
* 正则化。
* 参数估计。
* 误差修正。

适用论文位置：

* 参数辨识。
* 数据拟合。
* 图像重建。
* 模型校准。

风险：
反问题可能病态，对噪声敏感。必须说明正则化或误差处理方法。
