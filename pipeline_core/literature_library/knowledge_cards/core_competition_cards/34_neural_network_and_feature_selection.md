# 知识卡：神经网络与特征选择

来源文献：
- Zhou2016MachineLearning

* Tan2005MathModel
* Xia2016MathModelMATLAB
* Si2015ModelingAlgorithmsApplications

知识类别：机器学习 / 分类预测
适用题型：分类、诊断、模式识别、复杂非线性预测
引用等级：B_textbook

核心思想：
神经网络适合处理复杂非线性关系，特征选择用于减少冗余变量并提高模型稳定性。

常见流程：

1. 数据清洗。
2. 特征标准化。
3. 特征选择。
4. 划分训练集和测试集。
5. 建立模型。
6. 训练。
7. 验证。
8. 输出准确率、召回率、误差等指标。

适用场景：

* 数据量较充足。
* 变量较多。
* 机理关系不明确。
* 需要分类或预测。

风险：
黑箱性强。竞赛论文中必须配合可解释性分析和对照模型。
