# 知识卡：综合评价与决策方法

来源文献：

* Si2015ModelingAlgorithmsApplications
* Tan2005MathModel
* Zhang2024ProbabilityStatistics

知识类别：评价模型 / 决策分析
适用题型：多指标评价、方案排序、质量评价、风险评价、城市/企业/系统综合评价
引用等级：A_competition_algorithm_textbook

核心思想：
综合评价方法将多个指标转化为综合得分或排序结果，用于比较多个对象或方案。

常见方法：

1. 理想解法。
2. 模糊综合评判法。
3. 数据包络分析 DEA。
4. 灰色关联分析。
5. 主成分分析。
6. 秩和比综合评价法。
7. 案例综合分析。

适用场景：

* 指标多。
* 评价对象多。
* 指标量纲不同。
* 需要排序。
* 需要决策建议。

生产线要求：

1. 指标正向化。
2. 指标标准化。
3. 权重来源说明。
4. 敏感性分析。
5. 与至少一种对照评价方法比较。

风险：
权重主观性和指标选择偏差是主要风险。
