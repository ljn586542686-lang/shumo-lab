# 知识卡：凸性识别与凸优化建模

来源文献：
- Boyd2004ConvexOptimization

知识类别：
凸优化理论

适用题型：
连续优化、资源分配、拟合、几何优化、鲁棒优化

引用等级：
A_convex_optimization_textbook

核心思想：
凸优化的关键不是直接套算法，而是识别或重构问题，使目标函数和可行域满足凸性。若目标为凸函数且约束形成凸集，则局部最优也是全局最优，并可使用可靠的凸优化算法求解。

适用场景：
- 目标函数可表示为凸函数。
- 约束可表示为仿射约束、凸不等式或标准锥约束。
- 需要解释局部最优与全局最优关系。
- 需要提高优化模型理论可信度。

风险：
不能只因为用了优化求解器就说问题是凸的。必须检查目标函数、约束和变量定义。
