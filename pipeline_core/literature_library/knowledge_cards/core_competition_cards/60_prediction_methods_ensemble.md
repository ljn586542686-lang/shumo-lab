# 知识卡：预测方法综合库

来源文献：
- Zhou2016MachineLearning

* Si2015ModelingAlgorithmsApplications
* Tan2005MathModel
* Zhang2024ProbabilityStatistics
* Xia2016MathModelMATLAB

知识类别：预测模型
适用题型：趋势预测、需求预测、人口预测、系统演化、时间序列
引用等级：A_competition_algorithm_textbook

核心思想：
预测题不应只依赖单一模型，应根据数据特征选择灰色预测、微分方程、差分方程、时间序列、插值拟合、神经网络等方法，并通过误差比较选择最终模型。

常见方法：

1. 微分方程模型。
2. 灰色预测模型。
3. 差分方程。
4. 马尔可夫预测。
5. 时间序列。
6. 插值与拟合。
7. 神经元网络。

适用场景：

* 数据少：灰色预测。
* 机理明确：微分方程。
* 周期明显：时间序列。
* 状态转移明显：马尔可夫。
* 非线性复杂：神经网络。
* 需要平滑补点：插值拟合。

风险：
预测题必须设置误差指标、验证集或历史回测。不能只展示未来曲线。
