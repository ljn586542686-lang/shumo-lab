# 知识卡：目标规划

来源文献：

* Si2015ModelingAlgorithmsApplications
* Pu2024OperationsResearch

知识类别：多目标优化 / 目标偏差控制
适用题型：多目标资源配置、计划制定、生产安排、综合目标折中
引用等级：A_competition_algorithm_textbook

核心思想：
目标规划将多个目标转化为目标值与偏差变量，通过最小化偏差实现多目标折中。

常见元素：

* 目标值。
* 正偏差变量。
* 负偏差变量。
* 优先级。
* 权重。
* 资源约束。

适用场景：

* 多个目标难以同时最优。
* 目标有优先级。
* 需要尽量接近多个预设目标。
* 生产计划或资源配置。

风险：
目标值和优先级具有主观性，必须说明设定依据。
