# 知识卡：图论、最短路、最小生成树与 TSP

来源文献：

* Si2015ModelingAlgorithmsApplications
* Tan2005MathModel
* Pu2024OperationsResearch

知识类别：图与网络模型
适用题型：路径规划、网络设计、物流、通信、巡检、旅游商问题
引用等级：A_competition_algorithm_textbook

核心思想：
将实际系统抽象为图 G=(V,E)，节点表示地点或状态，边表示连接关系、距离、成本或时间。根据问题目标选择最短路、最小生成树、最大流、最小费用流或旅行商模型。

常见模型：

1. 最短路问题。
2. 最小生成树问题。
3. 最大流问题。
4. 最小费用流问题。
5. 旅行商 TSP。
6. 关键路径问题。

适用场景：

* 道路网络。
* 物流配送。
* 通信网络。
* 管网设计。
* 巡检路径。
* 任务访问顺序。

风险：
TSP 和车辆路径类问题复杂度高，规模较大时需要启发式或近似算法。
