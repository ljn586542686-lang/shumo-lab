# 知识卡：单纯形法与线性规划灵敏度分析

来源文献：
- Boyd2004ConvexOptimization

* Pu2024OperationsResearch

知识类别：优化算法 / 灵敏度分析
适用题型：线性规划、资源约束变化、目标系数变化
引用等级：A_textbook

核心思想：
单纯形法通过在可行域顶点之间迭代寻找最优解。灵敏度分析用于判断目标系数、资源约束或右端项变化对最优解的影响。

适用场景：

* 线性规划模型已经建立。
* 需要解释资源变化对结果的影响。
* 需要说明模型稳定性。
* 需要回答“若资源增加/减少怎么办”。

常见分析对象：

1. 目标函数系数变化。
2. 约束右端项变化。
3. 影子价格。
4. 约束是否紧绑定。
5. 最优基是否保持不变。

可复用论文位置：

* 模型求解
* 灵敏度分析
* 结果解释
* 政策建议

风险：
只适用于线性规划框架。非线性模型不能直接套用单纯形灵敏度结论。
