# 知识卡：交通流模型

来源文献：

* Tan2005MathModel
* Pu2024OperationsResearch

知识类别：交通系统 / 排队 / 流量模型
适用题型：拥堵分析、路口控制、通行能力、交通规划
引用等级：A_textbook

核心思想：
用流量、速度、密度、等待时间等变量刻画交通系统，并根据道路、信号灯、服务能力或车辆行为建立模型。

常见变量：

* 流量 q。
* 密度 k。
* 速度 v。
* 等待时间 W。
* 到达率 lambda。
* 服务率 mu。

常见关系：
q = k v

适用场景：

* 交通流连续建模。
* 路口排队。
* 道路通行能力。
* 信号灯优化。
* 车辆间隔。

风险：
交通流具有随机性和时变性。不能只用静态平均值解释动态拥堵。
