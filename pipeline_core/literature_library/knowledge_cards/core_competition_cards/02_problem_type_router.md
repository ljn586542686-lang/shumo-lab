# 知识卡：题型识别与方法路由

来源文献：

* Tan2005MathModel
* Pu2024OperationsResearch
* Zhang2024ProbabilityStatistics

知识类别：题型路由
适用题型：所有新赛题
引用等级：A_textbook

核心思想：
先判断题目本质，再选择方法。不要先套模型。题型识别决定后续模型路线、文献调用、数据处理和论文结构。

常见题型：

1. 优化类：资源配置、路径规划、调度、选址、装载。
2. 预测类：时间序列、趋势外推、人口预测、需求预测。
3. 评价类：多指标综合评价、方案排序、风险评价。
4. 仿真类：交通流、排队、物理过程、生态系统。
5. 统计类：参数估计、抽样误差、分布拟合、置信区间。
6. 网络类：最大流、最小费用流、物流、供应链。
7. 决策类：风险决策、不确定决策、决策树。
8. 对策类：多主体竞争、攻防策略、博弈。
9. 机理类：微分方程、守恒方程、动力学模型。
10. 软件实现类：MATLAB/Python 数值求解、插值、拟合、可视化。

Codex 路由规则：

* 出现“最大/最小/最优/安排/分配/调度”：优先考虑优化模型。
* 出现“预测/趋势/未来/增长”：优先考虑预测与统计模型。
* 出现“评价/排序/优劣/风险”：优先考虑综合评价与决策模型。
* 出现“流量/排队/等待/服务”：优先考虑排队论或交通流。
* 出现“网络/节点/边/路径/容量”：优先考虑图论和网络流。
* 出现“传播/感染/扩散”：优先考虑传染病模型或扩散模型。
* 出现“随机/概率/不确定”：优先考虑概率统计模型。
* 出现“物理过程/运动/热/流体/力”：优先考虑机理模型。

风险：
题型可能混合，不能单一路由。复杂赛题通常需要“主模型 + 辅助模型 + 检验模型”。
