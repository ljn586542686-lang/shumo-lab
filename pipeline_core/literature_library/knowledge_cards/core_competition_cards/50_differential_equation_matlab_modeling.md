# 知识卡：微分方程建模与 MATLAB 数值解

来源文献：

* Si2015ModelingAlgorithmsApplications
* Tan2005MathModel
* Xia2016MathModelMATLAB

知识类别：动态系统 / 数值求解
适用题型：人口、传染病、运动、衰变、工程系统、初值/边值问题
引用等级：A_competition_algorithm_textbook

核心思想：
用微分方程描述系统状态随时间或空间变化的规律，再通过 MATLAB 数值求解得到动态轨迹。

常见问题：

* 初值问题。
* 边值问题。
* 人口模型。
* 放射性衰变。
* 飞行/运动过程。
* 物理过程模拟。

常见工具：

* ode45
* ode15s
* bvp4c
* 数值积分
* 参数扫描

风险：
步长、初值、参数和方程刚性会显著影响结果。必须进行稳定性或敏感性检查。

## 公式细节边界

公式细节需查原书对应章节。知识卡仅作为方法选择和风险审查依据，不得直接替代论文中的模型推导。
