# 知识卡：神经网络与反向传播

来源文献：
- Zhou2016MachineLearning

知识类别：
非线性学习模型

适用题型：
复杂非线性预测、分类、回归、模式识别

引用等级：
A_machine_learning_textbook

核心思想：
神经网络通过多层非线性映射学习输入与输出之间的复杂关系，常用反向传播算法更新参数。

适用场景：
- 样本量较充足。
- 非线性关系复杂。
- 机理关系不明确。
- 作为预测增强模型或对照模型。

生产线调用：
- model-route-generator
- optimizer-arena
- model-critic

风险：
黑箱性强，易过拟合。数模论文中必须配合基准模型、误差分析和特征解释。

需要人工查书补充：
公式细节需查原书对应章节。
