# 知识卡：多元分析方法

来源文献：
- Zhou2016MachineLearning

* Si2015ModelingAlgorithmsApplications
* Zhang2024ProbabilityStatistics

知识类别：多变量统计
适用题型：指标降维、分类、聚类、综合评价、变量关系分析
引用等级：A_competition_algorithm_textbook

核心思想：
多元分析用于处理多个变量之间的关系，帮助降维、分类、聚类和综合解释。

常见方法：

1. 聚类分析。
2. 主成分分析。
3. 因子分析。
4. 判别分析。
5. 典型相关分析。
6. 对应分析。
7. 多维标度法。

适用场景：

* 指标较多。
* 变量相关性强。
* 需要降维。
* 需要群体分类。
* 需要综合评价。

风险：
降维后主成分或因子必须解释清楚，不能只给计算结果。
