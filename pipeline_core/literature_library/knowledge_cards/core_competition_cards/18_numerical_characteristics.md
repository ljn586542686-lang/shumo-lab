# 知识卡：随机变量数字特征

来源文献：

* Zhang2024ProbabilityStatistics

知识类别：统计描述
适用题型：数据摘要、结果评价、波动性分析、风险分析
引用等级：A_textbook

核心思想：
期望、方差、标准差、协方差、相关系数等数字特征可以概括随机变量的中心趋势、离散程度和变量关系。

常见指标：

* 期望。
* 方差。
* 标准差。
* 协方差。
* 相关系数。
* 偏度。
* 峰度。

适用论文位置：

* 数据预处理。
* 描述性统计。
* 误差分析。
* 风险分析。
* 变量相关性分析。

风险：
相关不代表因果。相关系数不能直接证明变量之间存在因果关系。

## 公式细节边界

公式细节需查原书对应章节。知识卡仅作为方法选择和风险审查依据。不得直接替代论文中的模型推导。
