# 知识卡：凸集与凸函数

来源文献：
- Boyd2004ConvexOptimization

知识类别：
凸分析基础

适用题型：
凸优化、几何优化、约束重构、可行域分析

引用等级：
A_convex_optimization_textbook

核心思想：
凸集和凸函数是判断问题是否可用凸优化处理的基础。凸集要求集合内任意两点连线仍在集合内，凸函数要求函数值不超过端点函数值的线性插值。

适用场景：
- 判断可行域是否凸。
- 判断目标函数是否凸。
- 检查约束变换是否保持凸性。
- 为 KKT 或内点法提供理论前提。

生产线调用：
- theory-checker
- model-route-generator
- model-critic
- optimizer-arena

风险：
整数变量、乘积变量、组合约束通常会破坏凸性，需要单独处理。
