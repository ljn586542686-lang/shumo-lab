# 知识卡：竞赛算法选择策略

来源文献：
- Nocedal2006NumericalOptimization
- Boyd2004ConvexOptimization
- Zhou2016MachineLearning

* Si2015ModelingAlgorithmsApplications
* Tan2005MathModel
* Pu2024OperationsResearch
* Xia2016MathModelMATLAB

知识类别：竞赛策略 / 模型路线选择
适用题型：所有数学建模竞赛题
引用等级：pipeline_rule

核心思想：
正式比赛中应根据题型、数据量、时间限制和解释要求选择模型。最佳策略通常不是最复杂算法，而是“基准模型 + 主模型 + 对照模型 + 敏感性分析 + 证据链”的组合。

推荐选择逻辑：

1. 数据少、机理强：优先机理模型。
2. 数据多、关系复杂：考虑统计/机器学习模型。
3. 有明确约束和目标：优先优化模型。
4. 多指标排序：优先综合评价模型。
5. 网络结构明显：优先图论或网络流模型。
6. 随机性强：加入概率统计或仿真。
7. 结果解释要求高：避免单独使用黑箱模型。
8. 冲奖目标：必须有算法擂台和敏感性分析。

输出要求：

* 至少 3 条候选路线。
* 至少 1 个基准模型。
* 至少 1 个主模型。
* 至少 1 个对照模型。
* 至少 1 类稳健性检验。

风险：
不要机械套用模型。每个模型必须能对应题目目标、数据结构和输出要求。
