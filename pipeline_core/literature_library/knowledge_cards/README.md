# 五教材知识卡库说明

本知识卡库由五本教材蒸馏而成：

1. 《数学模型》：提供数学建模流程和多类型案例基础。
2. 《运筹学》：提供线性规划、运输、动态规划、库存、排队、决策论等优化基础。
3. 《数学建模与MATLAB应用》：提供 MATLAB 实现、绘图、插值、数值计算和案例求解基础。
4. 《概率论与数理统计》：提供概率、随机变量、分布、参数估计、统计推断和误差分析基础。
5. 《数学建模算法与应用（第2版）》：提供数学建模竞赛常用算法、现代优化、图像处理、支持向量机、多元分析、综合评价、预测、目标规划和 MATLAB/Lingo 实现强化。

使用原则：

1. 题型识别时调用 knowledge_card_router.md。
2. 模型路线生成时优先组合 2–5 张知识卡。
3. 每篇论文不需要引用所有教材，只引用真正支撑模型的方法来源。
4. 教材适合支撑方法框架，具体赛题结论必须由输出结果和证据链支撑。
5. 现代优化、SVM、神经网络、图像处理等高级方法，正式论文最好补充专题论文。
6. 若知识卡提示“公式细节需查原书对应章节”，Codex 不得自行补公式。
7. 所有引用必须经过 citation-auditor。
8. 所有结论必须经过 evidence-trace-checker。
9. 所有 AI 参与必须写入 ai_disclosure。
# 八教材知识卡库 v3.0 说明

新增三本高级教材后，知识库分层如下：

第一层：五本原有教材  
作用：提供数学建模、运筹优化、MATLAB、概率统计、竞赛算法的通用基础。

第二层：三本高级教材  
作用：提升本科组和国奖冲击所需的理论深度。
- Nocedal2006NumericalOptimization：支撑数值优化求解、局部优化、非线性约束优化、收敛与停止准则。
- Boyd2004ConvexOptimization：支撑凸优化、对偶、KKT、灵敏度、鲁棒拟合、内点法。
- Zhou2016MachineLearning：支撑机器学习建模、评估、SVM、神经网络、集成学习、聚类、降维、特征选择。

使用原则：
1. 不强制每篇论文都引用高级教材。
2. 只有当正文涉及对应理论时才引用。
3. 若论文使用非凸局部优化，应引用 Nocedal，但不得宣称全局最优。
4. 若论文能证明凸性，可引用 Boyd，并说明凸性来源。
5. 若论文使用机器学习，必须引用 Zhou，并执行机器学习审查清单。
6. 高级教材不能支撑具体赛题数值结论，数值结论必须来自 output 和 evidence_map。
7. 所有高级理论引用必须通过 citation-auditor。
