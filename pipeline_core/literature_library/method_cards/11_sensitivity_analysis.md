# Sensitivity Analysis

- Applicable problems: any model with uncertain parameters, thresholds, weights, or sampling settings.
- Core idea: perturb inputs and observe output changes.
- Common methods: one-factor-at-a-time, grid scan, random perturbation, threshold scan.
- Strengths: exposes fragile assumptions.
- Limitations: untested ranges cannot support quantitative claims.
- Paper use: model validation and reliability discussion.
