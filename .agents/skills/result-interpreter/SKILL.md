# Result Interpreter

## 角色定位

你负责把模型结果解释成评委能读懂、能相信、能对应题目的结论。你的任务不是凭空写漂亮话，而是把真实模型输出转化为论文中的结果分析。

必须坚持：

```text
没有数据支撑的结论不写。
没有图表对应的趋势不写。
没有模型输出的数值不编。
```

解释前必须建立 evidence map。没有 evidence map 的核心结论不得写入论文。

## 适用场景

当出现以下情况时使用本 skill：

- MATLAB 已生成结果。
- `output/result_summary.txt` 已存在。
- `output/tables` 中已有结果表。
- `output/figures` 中已有图。
- 已完成灵敏度分析。
- 论文需要“结果分析”“模型结果”“灵敏度分析解释”。
- 现有结论空泛，例如“模型效果较好”。

## 输入材料

优先使用：

```text
output/result_summary.txt
output/model_log.txt
output/sensitivity_report.txt
output/tables
output/figures
paper/model_critique.md
```

也可参考：

- 题目分析报告。
- 数据审计报告。
- 模型选择报告。
- MATLAB 代码中的变量含义。
- 用户补充的业务解释。

## 默认输出

建议输出：

```text
paper/result_interpretation.md
paper/conclusion_points.md
paper/evidence_map.md
```

如果不写文件，则直接输出结果解释报告。

## 解释原则

1. 每个结论必须有数据、图表或模型输出支撑。
2. 每个问题必须分别回答。
3. 优先解释关键变量、主要差异和异常结果。
4. 不写“科学合理”“效果较好”这类空泛句。
5. 对反直觉结果必须解释可能原因。
6. 灵敏度结论要说明哪个参数更关键。
7. 图表不是装饰，必须服务于论证。
8. 论文结论要能回扣赛题问题。
9. 每条核心结论必须标注来源文件或图表编号。

## Evidence Map 要求

每个核心结论必须对应至少一个证据来源。允许来源包括：

- `output/result_summary.txt`
- `output/model_log.txt`
- `output/sensitivity_report.txt`
- `output/tables`
- `output/figures`
- 代码变量、目标函数、约束和参数设置
- `paper/decision_log.md`

建议输出到：

```text
paper/evidence_map.md
```

格式：

```markdown
| 结论编号 | 结论 | 来源文件 | 来源位置/字段 | 支撑类型 | 风险 |
|---|---|---|---|---|---|
```

支撑类型可写：

- 数值结果
- 图表趋势
- 表格统计
- 模型约束
- 灵敏度分析
- 人工决策记录

风险标记：

- `低`：来源清楚，口径一致。
- `中`：来源存在，但论文表达需要谨慎。
- `高`：来源不足，不应写入论文。

写作时必须优先使用低风险结论；高风险结论必须删除、降级为局限性，或返回模型/输出阶段补证据。

## 必须覆盖内容

### 1. 分问题结果解释

对每一问分别说明：

- 该问模型输出了什么。
- 最重要的数值是多少。
- 结果说明了什么。
- 该结果如何回答题目。
- 是否存在需要谨慎解释的地方。

### 2. 主要结果

根据实际输出回答：

- 最优方案是什么。
- 核心目标值是多少。
- 排名或分类结果是什么。
- 预测趋势是什么。
- 与基准方案相比变化多少。
- 关键对象、关键时段或关键区域是什么。

### 3. 表格解释

每张关键表至少说明：

- 表格展示了什么。
- 哪一列是核心指标。
- 最大值、最小值或变化最大的对象。
- 结果是否符合常识。
- 表格对应赛题哪一问。
- 表格能支撑哪条论文结论。

推荐句式：

```text
由表 X 可知，方案 A 的总收益为 ...，较基准方案提高 ...%。这说明在当前约束条件下，...
```

### 4. 图表解释

每张关键图至少说明：

- 图展示了什么。
- 横轴、纵轴或颜色含义。
- 最重要的变化趋势。
- 是否存在拐点、峰值、低谷或异常点。
- 该趋势对模型结论的意义。

推荐句式：

```text
图 X 显示，随着参数 p 增大，目标函数值整体呈上升趋势，但在 p 超过 ... 后增幅明显减小，说明 ...
```

### 5. 灵敏度分析解释

必须说明：

- 扰动了哪些参数。
- `±5%`、`±10%`、`±20%` 下结果是否稳定。
- 哪些参数对目标值影响最大。
- 敏感性排序是什么。
- 对实际方案有什么启示。
- 是否暴露模型风险。

推荐句式：

```text
当销售价格下降 10% 时，总收益下降 8.7%；当亩产量下降 10% 时，总收益下降 12.4%。说明模型对亩产量变化更加敏感，后续方案应优先关注产量稳定性。
```

### 6. 异常结果解释

如果出现以下情况，必须解释：

- 某个对象排名反常。
- 某个类别样本过少或过多。
- 某个参数扰动导致结果突变。
- 模型输出接近约束边界。
- 最优方案过度集中。
- 某个变量影响方向与常识相反。

解释时优先从以下角度分析：

- 数据分布。
- 约束条件。
- 指标权重。
- 参数设置。
- 样本差异。
- 现实机制。

### 7. 局限性解释

如存在以下问题，应写入局限性：

- 数据缺失或口径不一致。
- 参数估计存在不确定性。
- 未考虑某些现实约束。
- 模型假设较强。
- 求解结果依赖特定场景。
- 样本量有限。
- 外部环境变化未充分建模。

局限性不能写成削弱全文可信度的否定句，应写成可接受的竞赛论文表达。

## 不合格表达

避免：

```text
结果表明模型科学合理。
```

```text
由图可知趋势明显。
```

```text
该模型具有较好的适用性。
```

```text
综上，本文方法有效。
```

这些句子没有数据支撑，不能作为高水平数模论文结论。

## 合格表达

推荐：

```text
由表 X 可知，排名前三的对象分别为 A、B、C，其综合得分均高于 0.80，明显高于样本均值 0.57，说明这三类对象在收益、稳定性和资源利用率上具有综合优势。
```

```text
灵敏度分析显示，当成本参数上升 20% 时，目标函数值下降 15.3%，但最优方案的前两类决策保持不变，说明模型在中等成本波动下具有一定稳定性。
```

```text
图 X 中第 7 组样本表现出明显偏离，结合数据审计结果可知，该样本在成本字段上高于上四分位数 1.5 倍 IQR，因此其排名下降主要受成本异常偏高影响。
```

## 质量标准

合格解释必须满足：

- 每个问题都有明确回答。
- 每个核心结论都有数据来源。
- 每个核心结论都进入 evidence map。
- 图表不是装饰，而是支撑结论。
- 灵敏度分析说明关键风险。
- 不凭空编造未运行出的结果。
- 语言像竞赛论文，而不是 AI 模板。
