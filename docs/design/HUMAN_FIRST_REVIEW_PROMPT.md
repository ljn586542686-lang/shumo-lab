# Human-First 论文人工评审流程模板（仓库级通用版）

本文件是人工评审的操作模板，不是自动化 gate 或机器评分器。每一步都
需要人工判断，不产出通过/不通过的机械裁决，只产出供人工决策参考的
结构化记录。适用于任何 case 的论文正文评审，不针对特定题目。

本模板由 `work_tmp/human_first_ab/p03_nanny_service_ab1/
REUSABLE_HUMAN_FIRST_REVIEW_PROMPT.md`（样本2实验产物）提炼而来，
去除了样本专属路径引用；样本专属版本本身不再修改，仅作历史记录保留。

## 固定流程

```
通读
  ↓
独立数值复核
  ↓
数学、表格与代码一致性核验
  ↓
推导连贯性人工通读
  ↓
残留问题与接受风险清单
```

## 第一步：通读

- 若有匿名版本可用（例如按 Human-First 契约独立设计的 A/B 对照材料），
  使用匿名版本，评审前不查看映射关系；若无匿名版本，正常通读全文。
- 先完整读一遍，不做笔记；再回答关键结论的复述问题（能否不看稿说明
  模型选择依据、目标函数每项含义、关键约束限制什么）。
- 记录：通读时间、脱稿回答关键问题的耗时、是否需要翻回原文才能作答
  （若需要，记录具体位置——这本身是一个信号，说明该处推导没有讲
  清楚）。
- 优先由与本次写作过程无关的评审者完成，避免评审者因知晓写作过程
  而产生先入为主的判断。

## 第二步：独立数值复核

- 不参考论文附带的验证程序输出，独立重新核对论文中报告的每一个
  关键数值结果。
- 至少验证：最终结果数值本身、结果对应的具体方案（如变量取值）、
  任何声称"唯一""最优""并列"的表述是否有支持证据。
- 若评审者的复核结果与论文报告不一致，记录差异，不自行判断谁对
  谁错，交由后续步骤处理。

## 第三步：数学、表格与代码一致性核验

- 若该 case 有数学锁定清单（记录题面数据、公式、结果的文件），
  逐项核对论文中的公式、数据、结果是否与锁定清单完全一致；若无
  正式锁定清单，对照题目原始材料本身核对。
- 检查代码附录（如有）：是否可读、是否与正文描述的算法逻辑一致、
  是否存在正文声称"已验证"但代码中实际未实现的情况。
- 检查是否存在未在题面或锁定清单中出现、却被引入正文的新数值、
  新方法或新结论。

## 第四步：推导连贯性人工通读

逐节检查是否存在以下问题（供参考，不是机械检测规则，不得转为
关键词计数或阈值判定）：

**内容完整性**：

- 公式在没有说明来源或动机的情况下直接出现；
- 使用"显然""可得""容易证明"等词跳过了决定模型结构或结果可信度
  的关键推导步骤；
- 关键假设被当作题面既定事实叙述，而实际是建模者自行补充的选择
  （对照 `HUMAN_FIRST_MODELING_LOGIC_CONTRACT.md` 原则 B、§十三
  的样本实例）；
- 结果表格后没有讨论，或讨论只是复述表格数字而没有解释其含义；
- 结论部分只重复数值，没有逐项对应回答题目问题；
- 是否存在虚构的"尝试-失败-改进"探索过程；
- 验证方法的声称范围是否超出实际验证范围（对照契约 §九）；
- 是否存在方法选择的绝对化措辞（对照契约 §十）。

**长度与密度**（对照契约 §十二篇幅优先级）：

- 是否存在同一建模动机被反复完整解释——按契约原则，同一动机
  原则上只完整解释一次，重复出现的应是简要复述或引用，不是
  再展开一遍；
- 是否存在非必要的技术岔路——例如展开了一个最终没有采用、也不
  影响正文结论的方法论证，只是为了显得全面；
- 是否为了显得高级而加入与题目本身无关的方法或模块（多模型融合、
  无必要的敏感性分析、无必要的指标层，见契约原则 A）。

## 第五步：残留问题与接受风险清单

评审结束后，整理一份清单，至少包括：

- 尚未解决或有争议的问题（如某处推导评审者本人也存疑、某个建模
  假设的现实合理性存疑）；
- 若接受当前稿件作为提交/参考版本，需要承担的已知风险；
- 是否需要人工修订后再评审一轮，还是可以直接采用。

## 使用边界

- 本流程模板不产出 PASS/FAIL 或任何形式的自动裁决；所有判断由
  参与评审的人工完成。
- 本流程模板不得被改写为脚本化的关键词检测、篇幅阈值判定或自动
  评分公式，也不得接入 `package_candidate`/`final_freezer` 等
  自动化 gate 链路——评审结论只是供人工决策参考的记录，不构成
  任何 gate 的通过/阻断依据。
- 若某一步骤的结论依赖对原始材料的直接核对而当前环境无法完成
  （例如字体渲染故障导致无法读取某文件的中文内容），评审者需
  使用具备完整能力的环境重新核实，不能依赖间接推断。
